UNIT 1 — Fundamentals of Computers

1.1 Data vs Information

Data: Data means raw, unorganised facts and figures which have no meaning by themselves. Data is the raw material of any computing system — it may be numbers, words, images, sounds or any other unprocessed record. Information: Information is processed, organised and meaningful data which is useful for taking decisions. Information is therefore the output of a processing system, whereas data is its input.
Hinglish: Data = kaccha maal 🔸, Information = pakka khana 🍛. Jaise "45, 78, 90, 33" ye sirf numbers hain (data). Lekin agar likha ho "Class 12 ka average score 61% hai" — ye information hai, kyunki iska matlab ban gaya. Yaad rakho: processing ke baad hi data "baat karne layak" banta hai.
Real life: (1) WhatsApp chat me type kiye words = data, par usi chat ka "poll result 60% YES" = information. (2) Bank statement ki saari entries = data, par "is mahine ₹12,000 kharch hue" = information. (3) Zomato par 10,000 orders ka record = data, par "aapke area me sabse zyada Paneer Tikka order hota hai" = information (jo Zomato apni strategy me use karta hai). (4) Aadhaar me 190+ crore records = data; "desh me kitne voters 18–25 age ke hain" = information. (5) Ek thermometer ka reading 40°C = data; "aaj heat-wave ka alert hai" = information.

DIKW Model (Data → Information → Knowledge → Wisdom)

The DIKW model explains how raw readings climb up to good decisions. Each higher level requires one more step of processing and judgement.

LevelQuestion it answersTemperature exampleCollege example
DataKya likha hai? (what)40 (just a number)85, 90, 78, 33
InformationIska matlab kya? (what + context)"Aaj ka temperature 40°C hai.""Class average 72% hai, aur 33 fail hua."
KnowledgeIsse hum kya samajhte hain? (how) "40°C me heatstroke ka risk hota hai, zyada paani peena chahiye.""Maths me weak students ki weekly test beech me rakhne se attendance kam hoti hai."

Common mistake: Sirf numbers ki list ko "information" likh dena. Rules to remember: (a) context/hawa-paani ke bina koi number information nahi banta; (b) same data se alag information nikal sakti hai (same marks se "topper kaun" bhi aur "fail kitne" bhi); (c) ek user ki information doosre user ke liye data ban sakti hai (e.g., monthly sales report → CEO ke liye data jab wo yearly trend banaye).

1.2 Information Processing Cycle

The Information Processing Cycle (IPOS) is the sequence a computer follows: Input → Process → Output → Storage. (Some books add a fifth step, Communication, because data now routinely travels between machines.) Every task on a computer — from adding two numbers to training an AI model — is some repetition of this cycle.
Hinglish: Computer ka poora kaam isi 4-step cycle me ghoomta rehta hai. Jaise chai banane ka cycle: samagri lao (input) → gas pe pakao (process) → cup me serve karo (output) → leftover fridge me rakho (storage). Cycle ruk nahi jaata — output aage ka input ban jaata hai.

Real life (UPI payment, step by step): Aapne ₹500 ka amount aur PIN diya = input; bank server ne balance check kiya, kat gaya = process; "Payment Successful" dikha = output; transaction history me entry save = storage; merchant app aur SMS ko message bhejna = communication. Poora kaam ~2 second me! Isi tarah IRCTC ticket booking, ATM cash withdrawal, Zomato order — sab IPOS ke hi variations hain.
Worked example (Excel marksheet): (1) Lab assistant ne students ke marks Excel me type kiye — input. (2) Formulas =SUM(B2:F2), =AVERAGE(B2:F2), =IF(G2>=40,"Pass","Fail") chal gaye — processing. (3) Screen par total, percentage aur PASS/FAIL dikha, printer se marksheet nikli — output. (4) File marksheet.xlsx save hui aur cloud par backup gaya — storage. (5) File HOD ko email/WhatsApp par bheji — communication. Bas — ek cycle complete! 🧮
GIGO ka connection: Cycle ka pehla stage sabse important hai. Agar input galat (roll no. galat, marks typo), to processing bilkul sahi chalega par output bhi galat hi aayega — "Garbage In, Garbage Out". Isliye real systems me input validation (range check, format check, mandatory fields) lagti hai. Computer input ki galti khud nahi sudharta — wo sirf instruction follow karta hai.

1.3 Introduction to Computers

A computer is an electronic device that accepts data as input, processes it according to a set of instructions called a program, stores it, and produces information as output. It works at extremely high speed, never gets tired, and follows instructions exactly — but it has no intelligence of its own.
Hinglish: Computer ek electronic naukar hai 😄 — jo bolega wahi karega, bas tez aur galti ke bina. Khud kuch nahi sochega — isliye "intelligence" wala kaam user ka (ya programmer ka), "execution" wala computer ka.
Real life: Jab aap phone par face-unlock karte ho (input: camera image, process: face matching, output: lock khul gaya, storage: log), jab ATM cash deta hai, jab Swiggy order ETA batata hai, jab college ka ERP attendance lagata hai — har jagah wahi ek computer ka basic model kaam kar raha hai. Aaj duniya me computer sirf laptop/desktop nahi — washing machine, car, drone, smart TV, smartwatch sabke andar computer (microcontroller) baitha hai.
Note (full form): "COMPUTER" ka full form "Commonly Operated Machine Particularly Used for Technological and Educational Research" — ye backronym hai (baad me banaya gaya). Asli word Latin "computare" (to calculate) se aaya hai. Exam me definition likhna, full form ratna optional. Par GIGO (Garbage In, Garbage Out) ka matlab zaroor likhna aata hai.

Stored Program Concept (von Neumann)

Program aur data dono ek hi memory me store hote hain; CPU memory se instruction laata hai, decode karta hai, execute karta hai. Isi idea ne modern computer banaya — pehle machines ko wire badal kar reprogram karna padta tha (jaise ENIAC ke plugboards). Ab sirf naya program memory me load karo, machine ka behaviour badal jaata hai. Aaj tak ke computers "von Neumann architecture" follow karte hain — bas performance features (cache, pipelining) add hue hain.

Signed Numbers & 2's Complement important

Negative numbers represent karne ke 3 tarike hain: Sign-Magnitude (pehla bit sign: 0=+, 1=−, baaki 7 bit magnitude), 1's Complement (saare bits ulto), 2's Complement (= 1's complement + 1). Computer 2's complement use karta hai kyunki isme subtraction ko addition se kar sakte hain — isliye CPU ko alag "subtract circuit" ki zaroorat nahi padti, aur -0 jaisa confusion bhi nahi hota.

(-5) ko 8-bit me kaise likhein?
   5            = 0000 0101
   1's complement = 1111 1010        (saare bits ulto)
   2's complement = 1111 1011       ✔ yahi hai (-5)

Check subtraction 7 − 5 using 2's complement:
   7            = 0000 0111
  -5 (2's form) = 1111 1011
  -----------------------------
   sum          = 1 0000 0010
   → carry (left wala 1) ko chhod do
   → 0000 0010 = 2 ✔  (7 − 5 = 2)

Another example: 12 − 9
   12 = 0000 1100
    9 = 0000 1001 → 1's = 1111 0110 → 2's = 1111 0111 = (−9)
   0000 1100 + 1111 0111 = 1 0000 0011 → carry hatao → 0000 0011 = 3 ✔

Pseudocode

Pseudocode is a way to write an algorithm using English-like statements mixed with programming keywords (IF, WHILE, PRINT) — kisi ek language ka strict syntax nahi hota, isliye ye language-independent plan hai. Ye code likhne se bilkul pehle ka step hai.
BEGIN                       BEGIN // factorial
  READ A, B                   READ N
  IF A > B THEN               F = 1
     PRINT "A is largest"     FOR I = 1 TO N DO
  ELSE                            F = F * I
     PRINT "B is largest"     END FOR
  END IF                      PRINT F
END                         END

BEGIN // even/odd           BEGIN // sum 1 to N
  READ N                      READ N
  IF N MOD 2 = 0 THEN         S = 0
     PRINT "Even"             FOR I = 1 TO N DO
  ELSE                            S = S + I
     PRINT "Odd"              END FOR
  END IF                      PRINT S
END                         END

Q1. Define data and information. Explain the difference with examples. (5)
Answer: Data means raw, unorganised facts and figures which have no meaning by themselves — e.g., marks 85, 90, 78. Information is processed, organised and meaningful data which is useful for taking decisions — e.g., "class average = 84.3%, 33 students pass hain". Difference ke 5 bases: meaning (data niraashray, information arthpurn), form (scattered vs organised), use (input vs output for decisions), dependency (information data par depend karti hai, ulta nahi), example (UPI transactions ki list = data, "is mahine ₹12,000 kharch" = information). Aage DIKW model se ek line jodo: data → information → knowledge → wisdom. Closing line: "computer ka poora kaam data ko information me badalna hai."
Q2. Explain the characteristics of a computer with examples. (5)
Answer: (1) Speed — lakhs of instructions per second; 3 GHz CPU 300 crore cycles/second chalata hai; Google 1 second me lakhs results. (2) Accuracy — 100% accurate; error sirf galat input se (GIGO); UPI me paisa exact katta hai. (3) Diligence — nahi thakta, same kaam baar-baar bina bore; ATM 24×7. (4) Versatility — ek machine, kai kaam; smartphone = camera + calculator + bank. (5) Storage — huge data, turant recall; Aadhaar ke crore records. (6) Automation — program ek baar likho, khud chalta rahe; traffic light. (7) No IQ, no feelings — khud decision nahi le sakta. (8) Economical — ek machine kai logon ka kaam. Closing: "inhi gunon ke saath limitations (bijli, GIGO, creativity nahi) bhi likhna" — examiner ko balanced answer pasand aata hai.
Q3. Explain the generations of computers with technology and examples. (10)
Answer: 1st (1940–56) vacuum tubes; punch cards/magnetic drums; machine language; ENIAC, UNIVAC — bade, garam, bijli-khor, bar-bar kharab. 2nd (1956–63) transistors; magnetic core; assembly + FORTRAN/COBOL; IBM 1401 — chhote, reliable, business use shuru. 3rd (1964–71) ICs; magnetic disk; high-level languages + OS; IBM 360 — time-sharing, kai users. 4th (1971–80) microprocessor/VLSI; semiconductor memory; GUI; IBM PC, Apple Macintosh — ghar-ghar computer. 5th (1980–present) ULSI + AI + parallel processing; flash/cloud; voice, ML; smartphones, supercomputers, AI tools. Trick: V-TIM-A. Closing line: "har generation me speed badhi, size ghati, cost giri, aur users badhe." Table banane par marks zyada milte hain.
Q4. Draw and explain the basic organization of a digital computer. (10)
Answer: Diagram me 5 units: Input → CPU (ALU + CU + Registers) → Output, Memory upar-neeche, aur buses. Input unit — keyboard/mouse/scanner data ko 0/1 me badalkar bhejta hai. Memory unit — primary (RAM/ROM/cache, chalte waqt) aur secondary (HDD/SSD, permanent). ALU — arithmetic (+ − × ÷) aur logical (compare, AND/OR) operations. CU — instruction fetch/decode karke baaki units ko control karta hai ("traffic police"). Output unit — result ko human-readable roop me deta hai (monitor/printer). Buses — data bus (data), address bus (kahan), control bus (commands). Aage stored program concept likho: program aur data ek hi memory me; isi se modern computers ka janm hua. Closing: von Neumann bottleneck — ek hi bus par data + instructions, isliye cache/pipelining aayi.

Trick — "MiMi-Mai-Su" order of power: Micro < Mini < Mainframe < Super (chhote se bade: Power ↑, Price ↑, Size ↑ except micro ki jagah nahi — yani micro sabse chhota). Ek line: "Chhota sasta — Bada mehnga — Sabse bada supercomputer". 💰

Aur "minicomputer" ka aaj ka naam "mid-range server" hai — term purani hai par concept live hai.

2.3 Central Processing Unit (CPU) — "Computer ka Dimaag"

The CPU is the brain of the computer; it executes instructions and controls the entire system. It has three parts: ALU, Control Unit (CU), and Registers. (On microcomputers, the CPU is contained in a single chip called a microprocessor.) CPU ki speed GHz (clock speed) me maapi jaati hai — 3.5 GHz ka matlab 3.5 billion cycles per second.

(a) ALU — Arithmetic Logic Unit

Do tarah ke operations karta hai: Arithmetic (+, −, ×, ÷, increment/decrement, comparison bhi) aur Logical (>, <, =, AND/OR/NOT, true/false decisions). Saara calculation — is notes file me jo bhi total/average nikala jaata hai — ALU hi karta hai.

Real life: Jab aap calculator me 45+55 dalte ho to jo answer 100 aata hai wo ALU ne nikala. Aur jab Swiggy "coupon apply hua ya nahi" check karta hai (discount > 0 AND order > 199) — ye logical operation wo bhi ALU hi karta hai. Jab online exam portal "marks >= 33 AND attendance >= 75" se PASS/FAIL decide karta hai — wahi ALU ka logic circuit. 🧠

(b) CU — Control Unit

Poori machine ka traffic police 🚦. Na khud calculate karta hai na store karta hai — bas instructions fetch karke decode karta hai aur doosre units ko command deta hai ki kya karna hai, kab karna hai. Clock ke saath synchronise ho kar poora instruction cycle chalata hai (fetch → decode → execute → store).

Real life: Restaurant manager jaisa — khud khana nahi banata, par "chef ko order do, waiter ko table 5 pe le jao" — sab coordinate karta hai. CU galat instruction address par bhej de to poora system hang — isliye modern CPUs me branch prediction lagti hai.

(c) Registers (CPU ke andar ki smallest & fastest memory)

Registers sabse chhoti aur sabse tez memory hain — CPU ke andar hi hote hain, aur instruction ke chalte waqt kaam aane wala data inme aata hai. Space bahut kam (8/16/32/64 bit per register) par speed nanoseconds me.

2.8 How CPU and Memory Work Together (program kaise chalta hai)

CPU teen (aur technically chaar) step ka cycle repeat karta hai: Fetch → Decode → Execute (aur phir Store). Ise instruction cycle (machine cycle) kehte hain, aur ye cycle ek clock (GHz) ke saath synchronise hota hai — kisi ek instruction me kai clock cycles lag sakte hain.
Instruction cycle (step-by-step):

1. FETCH   → PC batata hai agla instruction ka address
           → MAR me address jata hai → address bus par memory ko
           → memory se instruction aata hai → MDR → IR me load
2. DECODE  → CU instruction ko samajhta hai: "ye ADD karna hai"
           → kaunse operands chahiye, kahan se laane hain — sab decode
3. EXECUTE → zarurat ka data ALU me jaata hai → calculation/logic hota hai
           → result ACC/register me aata hai
4. STORE   → result ko register se RAM ke location me likh diya jaata hai
           → PC = PC + 1 (agla instruction) → cycle repeat 🔁

(Interrupt aaye to CPU saari state save karke interrupt handler chalata hai,
 phir wahi se resume — isliye music chalti rehti hai jab aap typing karte ho 🎵)
Real-life walkthrough — C ka line c = a + b; (a=5, b=3) computer ke andar:
1. Fetch: a aur b ki values RAM se registers me load hui (CPU ne memory read kiya).
2. Decode: CU ne instruction decode kiya: "add instruction hai, dono operands registers me hain".
3. Execute: ALU ne 5 + 3 = 8 nikala (add circuit), result ACC me aaya.
4. Store: Result 8 register se wapas variable c ki memory location me likha gaya.
5. Next: agla instruction chala — screen pe print karna, to output device ko bhej diya.

Isi ka naam "program execution" hai — aur ye cycle billions of times per second chalti hai. Insaan 1 second me ~1 thought-step leta hai, 3.5 GHz CPU 1 second me ~350 crore cycles 😎. Isliye loop 10 lakh baar chala kar bhi time nahi lagta.

Q3. Draw and explain the memory hierarchy. (5)
Answer: Diagram (upar se neeche): Registers → Cache (L1→L2→L3) → Primary memory (RAM/ROM) → Secondary storage (HDD/SSD) → Cloud/tape. (2) CPU ke registers/cache nanoseconds me, RAM microseconds(ish), disk milliseconds — isliye frequently used data cache me rakha jaata hai (locality of reference). (3) Hierarchy ka poora maksad: 90% accesses fast memory se serve ho jaayein aur slow/cheap memory sirf bulk storage ke liye rahe. 3.1 Operating System — Introduction & Functions

An Operating System (OS) is system software that acts as an interface between the user and the computer hardware. It manages all hardware resources (CPU, memory, I/O devices, files) and provides an environment in which application programs run. Do naam yaad rakho: OS ek resource manager bhi hai (kaun sa resource kisko, kitna milega) aur ek extended machine bhi (user ko hardware ki gandagi se bachakar simple interface deta hai).
Hinglish: OS = office ka manager 🧑‍💼. Aap (user) direct machine se baat nahi karte — manager se bolte ho, manager hardware (staff) ko kaam batata hai. Windows bolo to "file kholo" — Windows ne disk se file uthayi, RAM me daali, screen pe dikhayi. OS ke bina computer sirf plastic-metal ka dher hai.
Real life: Windows 11 (laptop), Android (phone), iOS (iPhone), Linux (servers/ATM/railway systems), macOS (Mac). Jab aap ek hi time pe song sunte ho, download karte ho aur PDF kholte ho — OS hi teeno ko CPU time barabar-baant deta hai (isliye app "hang" nahi hote hamesha). ATM ki screen, IRCTC ka server, JioFiber ka router — sab kisi na kisi OS par chal rahe hain.

CPU scheduling — worked example (numeral-based question)

Scheduling ka kaam: ready queue me se agla process chunna. Exam me chhota numerical aata hai — "average waiting time nikaalo". Waiting time = (process ke finish hone ka time − uska burst time − uske aane ka time). Simple example se samajh lo.
Teen processes (time 0 par aaye, CPU ek saath ek hi process chala sakta hai):
P1: 5 ms burst | P2: 3 ms burst | P3: 2 ms burst

(a) FCFS (jo pehle aaya, pehle chalega): P1 → P2 → P3
P1: 0 se 5    (wait 0)
P2: 5 se 8    (wait 5)
P3: 8 se 10   (wait 8)
Average waiting time = (0 + 5 + 8) ÷ 3 = 13 ÷ 3 ≈ 4.33 ms

(b) SJF (sabse chhota kaam pehle): P3 → P2 → P1
P3: 0 se 2    (wait 0)
P2: 2 se 5    (wait 2)
P1: 5 se 10   (wait 5)
Average waiting time = (0 + 2 + 5) ÷ 3 = 7 ÷ 3 ≈ 2.33 ms
→ SJF ne average waiting time kam kar diya (yehi iska fayda hai).

(c) Round Robin (time slice = 2 ms): P1 → P2 → P3 → P1 → P2 → P1
P1: 0–2, 6–8, 10–11  (total 5 ms mila)
P2: 2–4, 8–10        (total 3 ms)
P3: 4–6              (total 2 ms)
Sabko fair time mila, aur koi process zyada der "starve" nahi hua —
isliye time-sharing systems (Windows/Linux) me RR jaisa logic chalta hai.
Scheduling ke 4 naam yaad rakho: FCFS (simple, par chhota kaam bade ke peeche atak sakta hai), SJF (average waiting time sabse kam, par bade jobs starve ho sakte hain), Round Robin (fair, interactive systems ke liye), Priority (zaroori kaam pehle — ICU alarm > game download). Real OS inka mix use karte hain (multilevel feedback queue). ⏱️

3.4 The Unix Operating System & Basic Commands

Unix is a multi-user, multitasking, portable operating system developed at AT&T Bell Labs (1969) by Ken Thompson and Dennis Ritchie. Iska design itna strong tha ki Linux, macOS, Android aur aaj ke zyadatar servers usi ke concepts (file system, shell, permissions) pe chalte hain. C language bhi isi lab me (Ritchie ne) bani — isliye Unix ko "C me likha gaya OS" bolte hain.
Kahan milega: Bank ke ATM, IRCTC ke server, Google/Amazon ke data centre, Android phone (Linux kernel), aapka WiFi router, smart TV, aur aaj ka har cloud server — sab kisi na kisi Unix-family OS pe chal rahe hain 😲. 3.5 Microkernel-Based Operating System

A microkernel is a minimal OS kernel that contains only the most essential functions (basic process/memory management and inter-process communication). Baaki saari services — file system, device drivers, network stack — user space me separate processes ki tarah chalte hain aur kernel se message passing ke through baat karte hain.

3.6 Booting

Booting is the process of starting (loading) a computer — jab power button dabate ho tab OS ko memory me load karke computer ko usable banane ki process. Word "boot" "bootstrap" se aaya hai (jaise chappal ke strap se khud ko uthana — computer khud hi apne aap ko start karta hai).
Booting ke steps (exam me yahi likhna):

1. Power ON → SMPS sab parts ko current deta hai (CPU reset se start)
2. POST (Power On Self Test) → BIOS/UEFI hardware check karta hai
   (RAM kitni hai, keyboard hai? galat ho to beep 🔔)
3. BIOS/UEFI boot device dhundhta hai (boot order: HDD/SSD/USB/DVD/CD-ROM)
4. Bootloader (GRUB/Windows Boot Manager) load hota hai (MBR/EFI se)
5. OS kernel RAM me load hota hai → hardware drivers initialise
6. OS services start karta hai → login screen aa jaati hai ✅
   (Fir background me: user login → desktop → apps ready)

3.7 Introduction to Networks & Types of Networks

A computer network is a collection of two or more computers/devices connected together (wired or wireless) so that they can share data, resources (printer, internet, storage) and communicate. 4.1 Database, DBMS & Why Database

Database: An organised collection of related data stored in a structured way so that it can be easily accessed, managed and updated. DBMS: Software that allows users to create, store, retrieve, update and manage databases (and controls who can do what). Examples of DBMS: MySQL, Oracle, PostgreSQL, SQL Server, MongoDB.
Hinglish: Database = ek smart almari jisme har cheez apni jagah, labelled: ek drawer me students, ek me marks, ek me fees. DBMS = us almari ka caretaker 🧑‍🔧 jo bolne pe cheez nikaalta hai, nayi rakh deta hai, duplicate rok deta hai, aur unauthorised bande ko haath nahi lagane deta.
Real life: Aapka DigiLocker/Aadhaar (190+ crore records), IRCTC (railway seat booking), college ka ERP (attendance + marks + fees), PhonePe/UPI transactions, WhatsApp messages, Amazon/Flipkart ka inventory — sab DBMS (MySQL, Oracle, PostgreSQL, MongoDB) par chal rahe hain. -- DCL (permission dena/lena)
GRANT SELECT, INSERT ON student TO user_ansh;      -- right do

COMMIT;   -- poora transaction pakka ho gaya (permanent)
-- agar beech me error aa jaye to:
ROLLBACK; -- sab cancel (jaise kuch hua hi nahi)

Model answers — Unit 4 ke 4 sabse important questions

Q1. File system vs DBMS (10 points). (10)
Answer: (1) Storage — flat files vs central organised tables. (2) Redundancy — file system me zyada, DBMS me normalization se kam. (3) Consistency — file system me ek jagah update karne par doosri purani reh jaati hai; DBMS me single source. (4) Sharing/concurrency — file system multi-user ke liye nahi; DBMS me transactions + locking (ek saath kai users safe). (5) Security — file-level vs user/table/row-level permissions (GRANT/REVOKE). (6) Query — har search ke liye program vs SQL me 1 line. (7) Integrity — koi rule nahi vs constraints (PK/FK/CHECK/UNIQUE). (8) Backup/recovery — manual vs built-in + crash recovery. (9) Program-data independence — structure badla to program badla vs schema alag. (10) Cost/example — sasta (CSV/Excel) vs thoda mehnga (MySQL/Oracle). Closing: "isliye aaj ka har serious application — banking, railway, ERP — DBMS par chalta hai."
Q2. SQL ke sub-languages + commands. (5)
Answer: DDL (structure): CREATE, ALTER, DROP, TRUNCATE, RENAME. DML (data): INSERT, UPDATE, DELETE, SELECT. DCL (permissions): GRANT, REVOKE. TCL (transaction): COMMIT, ROLLBACK, SAVEPOINT. DQL (kuch books me select ke liye alag): SELECT. Saath me ek example har category ka likho: CREATE TABLE student(...); INSERT INTO student VALUES(...); GRANT SELECT ON student TO user1; COMMIT. Aur DELETE vs TRUNCATE vs DROP ka ek line add karo (kuch rows / saari rows / table hi gayab) — yahi question me twist hota hai.
Q3. Constraints kya hain? Koi 5 explain karo with examples. (5–10)
Answer: Constraints database par lagne wale rules hain jo galat data ko rok dete hain (integrity). (1) PRIMARY KEY — row ki unique identity, NULL nahi; roll_no INT PRIMARY KEY. (2) FOREIGN KEY — do tables ke beech link, value parent table me honi chahiye; course_id REFERENCES course(course_id). (3) UNIQUE — repeat nahi (NULL ho sakta hai); email VARCHAR(60) UNIQUE. (4) NOT NULL — column khali nahi; name VARCHAR(50) NOT NULL. (5) CHECK — condition; age INT CHECK(age>=17), marks 0–100. (6) DEFAULT — value na do to apne aap; city VARCHAR(30) DEFAULT 'Kichha'. Closing: "ye rules DBMS level par lagte hain, isliye application bug bhi galat data insert nahi kar sakta."
Q4. Transaction aur ACID properties. (5–10)
Answer: Transaction = operations ka ek group jo ek unit ki tarah chalta hai (ya poora ho ya kuch bhi nahi) — jaise ₹500 ka transfer (ek account se debit + doosre me credit). ACID: Atomicity — all-or-nothing (beech me fail hua to ROLLBACK, paisa kahin nahi kata). Consistency — transaction ke baad database valid state me (total paisa utna hi). Isolation — concurrent transactions ek doosre ko disturb na karein (locking). Durability — COMMIT ke baad data permanent (crash/power fail ke baad bhi safe). Saath me commands: START TRANSACTION → UPDATE/INSERT → COMMIT (pakka) ya ROLLBACK (undo) aur SAVEPOINT (beech ka point). Closing: "isi ACID ki wajah se UPI se paisa 'beech me' nahi ganwa hai."

  • Entertainment & business: Video, gaming, online shopping, digital payments.
  • Anonymity / open publishing: Koi bhi content publish kar sakta hai (blog, YouTube) — iske fayde-nuksaan dono (fake news bhi isi wajah se).
  • Interactive: Sirf padhna nahi — comment, video call, online banking, gaming bhi.
  • Scalable & resilient: Naye devices/connections lagte rehte hain; ek rasta fail ho to packet doosra rasta le leta hai.

5.5 Web Basics — Introduction to Web

WWW (World Wide Web) is a collection of web pages and documents stored on web servers, linked together with hyperlinks, and accessed over the internet using a web browser. 6. Tumhare clicks pe JS DOM update karta hai — bina page reload ke bhi kuch badal sakta hai

5.8 URL (Uniform Resource Locator)

A URL is the complete address of a resource (page, image, file) on the web. Isse browser ko pata chalta hai: kis protocol se, kis server se, kaunsi file maangni hai, kis data ke saath, aur page ke kis hisse par jaana hai.
https://www.surajmaluniversity.ac.in/bca/admission.html?year=2026#fees
└─┬─┘   └───────────┬───────────┘ └──────┬──────┘ └──┬──┘ └─┬─┘
protocol        domain name              path       query  fragment
  │                  │                     │           │       │
  1                  2                     3           4       5

1. Protocol     → https (kis tarah baat karni hai) — http/https/ftp
2. Domain/Host  → www.surajmaluniversity.ac.in (kis server se)
3. Port (optional) → :443 (default chhupa hota hai — http me 80)
4. Path         → /bca/admission.html (server me kaunsi file/page)
5. Query string → ?year=2026 (extra data bhejna; & se kai parameters)
6. Fragment     → #fees (page ke usi section par jump)
PointDetail

Model answers — Unit 5 ke 5 sabse important questions

Q1. Internet kya hai? Features aur services explain karo. (10)
Answer: Internet = global network of interconnected networks jo TCP/IP protocol use karte hain — "network of networks". History: ARPANET 1969 → TCP/IP 1983 → WWW 1989–91 (Tim Berners-Lee) → aaj 500+ crore users. Features: global reach, 24×7 availability, fast & cheap communication, huge information (WWW), any device (IoT), entertainment + business, open publishing, interactive. Services: WWW, e-mail (SMTP/POP3/IMAP), search engines, social media, e-commerce, e-banking/UPI, cloud storage, video conferencing, streaming, FTP, VoIP, e-learning/e-governance (SWAYAM, DigiLocker). Closing: "Internet infrastructure hai, WWW us par chalne wali ek service — ye farak exam me likhna mat bhoolna."
Q2. Difference between logical (IP) and physical (MAC) address. (5)
Answer: IP address software-level (network layer) address hai jo network admin ya DHCP server deta hai aur network badalne par badal jaata hai; IPv4 32-bit (192.168.1.1), IPv6 128-bit. MAC address hardware-level (data-link layer) address hai jo NIC par manufacturer ne factory me likha hota hai — 48-bit/12 hex digits (00:1A:2B:3C:4D:5E), aur mostly permanent. IP router internet par device dhundhne ke liye use karta hai ("ghar ka address"), MAC switch same LAN me device identify karne ke liye ("aadhaar number"). Real example: laptop ghar/college me IP badalta hai par MAC wahi rehta hai — isliye WiFi admin MAC se devices block kar sakta hai.
Q3. DNS kya hai? Working process explain karo. (5–10)
Answer: DNS (Domain Name System) human-readable domain names ko IP addresses me translate karta hai — "internet ki phone directory". Working: user www.surajmaluniversity.ac.in type karta hai → browser/OS apna cache + hosts file dekhta hai → nahi mila to ISP ke recursive resolver ko poochhta hai → resolver chain me Root server → TLD server (.in) → Authoritative nameserver se IP nikaalta hai (jaise 103.21.xx.xx) → browser us IP par HTTP/HTTPS request bhejta hai → page load + IP TTL ke hisaab se cache me save (agli baar fast). Records: A (IPv4), AAAA (IPv6), CNAME (alias), MX (mail), NS (nameserver). Closing: "DNS ki wajah se humein IP address yaad rakhne ki zaroorat nahi padti."
Q4. Difference between HTTP and HTTPS. (5)
Answer: HTTP (port 80) plain text me data bhejta hai — beech me koi padh sakta hai; browser "Not Secure" dikhata hai. HTTPS (port 443) SSL/TLS certificate se data encrypt karta hai — address bar me tala 🔒 dikhta hai; TLS handshake me server ka certificate verify hota hai aur session key banti hai. Kisliye: banking, UPI, login, shopping — jahan password/paisa ho. Common methods: GET (read), POST (form submit), PUT/PATCH (update), DELETE. Status codes: 200 OK, 301 redirect, 403 forbidden, 404 not found, 500 server error. Closing: "HTTPS bhejne ko safe karta hai, par site ke sahi hone ki guarantee certificate verification se aati hai — isliye scam sites bhi https le sakti hain."
Q5. HTML kya hai? HTML5 ke features + example program. (10)
Answer: HTML = markup language jo web page ka structure aur content banata hai (programming language nahi). Structure: <!DOCTYPE html> → <html> (head me meta/title; body me visible content). Example program me 5 tags likho: heading <h1>, paragraph <p>, image <img>, list <ul><li>, link <a href> — plus table/form ka mention. HTML5 features: audio/video tags (plugin-free), semantic tags (header/nav/section/article/footer — SEO + accessibility), canvas/SVG graphics, offline storage (localStorage), built-in form validation (required/type=email), mobile-friendly viewport. Closing: "HTML structure deta hai, CSS design, JavaScript behaviour — teeno milkar aaj ki websites banate hain."
