UNIT 1 — Fundamentals of Computers

1.1 Data vs Information

Data: Data means raw, unorganised facts and figures which have no meaning by themselves. Information: Information is processed, organised and meaningful data which is useful for taking decisions.
Hinglish: Data = kaccha maal 🔸, Information = pakka khana 🍛. Jaise "45, 78, 90, 33" ye sirf numbers hain (data). Lekin agar likha ho "Class 12 ka average score 61% hai" — ye information hai, kyunki iska matlab ban gaya.
Real life: (1) WhatsApp chat me type kiye words = data, par usi chat ka "poll result 60% YES" = information. (2) Bank statement ki saari entries = data, par "is mahine ₹12,000 kharch hue" = information. (3) Zomato par 10,000 orders ka record = data, par "aapke area me sabse zyada Paneer Tikka order hota hai" = information (jo Zomato apni strategy me use karta hai).
BasisDataInformation
MeaningRaw facts, no meaning aloneProcessed data, has meaning
FormUnorganised, scatteredOrganised, structured
UseInput for processingOutput, used in decision making
DependencyIndependentDepends on data
Example85, 90, 78 (marks)Class average = 84.3%

DIKW Model (Data → Information → Knowledge → Wisdom)

  • Data: 40°C — bas ek number.
  • Information: "Aaj ka temperature 40°C hai."
  • Knowledge: "40°C me heatstroke ka risk hota hai, zyada paani peena chahiye."
  • Wisdom: "Isliye school me afternoon assembly hataani chahiye" (knowledge ko apply karke sahi decision lena).

1.2 Information Processing Cycle

The Information Processing Cycle (IPOS) is the sequence a computer follows: Input → Process → Output → Storage. (Kuch books me 5th step "Communication" bhi jodte hain.)
Hinglish: Computer ka poora kaam isi 4-step cycle me ghoomta rehta hai. Jaise chai banane ka cycle: samagri lao (input) → gas pe pakao (process) → cup me serve karo (output) → leftover fridge me rakho (storage).
Real life (UPI payment): Aapne ₹500 ka amount aur PIN diya = input; bank server ne balance check kiya, katOT gaya = process; "Payment Successful" dikha = output; transaction history me entry save = storage.

1.3 Introduction to Computers

A computer is an electronic device that accepts data as input, processes it according to a set of instructions called a program, stores it, and produces information as output.
Hinglish: Computer ek electronic naukar hai 😄 — jo bolega wahi karega, bas tez aur galti ke bina. Khud kuch nahi sochega — isliye "intelligence" wala kaam user ka, "execution" wala computer ka.
Note: "COMPUTER" ka full form "Commonly Operated Machine Particularly Used for Technological and Educational Research" — ye backronym hai (baad me banaya gaya). Asli word Latin "computare" (to calculate) se aaya hai. Exam me definition likhna, full form ratna optional.

GIGO (Garbage In, Garbage Out): Agar input hi galat doge to output bhi galat hi milega — computer input ki galti khud nahi sudharta.

1.6 Basic Organization of a Digital Computer (von Neumann Architecture)

A computer has five basic units: Input Unit, Memory Unit, Arithmetic Logic Unit (ALU), Control Unit (CU), Output Unit. ALU + CU + Registers = CPU (Central Processing Unit). Ye 5 units buses (data bus, address bus, control bus) se jude hote hain.
Hinglish — kitchen analogy 🍳: Input unit = samagri laane wala; Memory = fridge (cheezein rakhne ki jagah); ALU = kadhai/tawa (yahan actual kaam — kaatna, pakana); CU = chef ka dimaag (kaun kab kya kare, wahi decide karta hai); Output = banaya hua khana. Bus = sab ke beech cheezein pahunchane wala waiter.

Stored Program Concept (von Neumann)

Program aur data dono ek hi memory me store hote hain; CPU memory se instruction laata hai, decode karta hai, execute karta hai. Isi idea ne modern computer banaya — pehle machines ko wire badal kar reprogram karna padta tha. (Aaj tak ke computers "von Neumann architecture" follow karte hain — bas performance feature add hue hain.)

Conversion Methods (step-by-step, exam me aise likho)

1) Decimal → Binary (2 se baar-baar divide karo; remainders ulta likho):

(25)₁₀
25 ÷ 2 = 12  remainder 1   ← LSB (last)
12 ÷ 2 = 6   remainder 0
 6 ÷ 2 = 3   remainder 0
 3 ÷ 2 = 1   remainder 1
 1 ÷ 2 = 0   remainder 1   ← MSB (first)

Ab neeche se upar padho: 1 1 0 0 1
=> (25)₁₀ = (11001)₂  ✔

2) Binary → Decimal (positions ka weight = 2ⁿ, phir jodo):

(11001)₂ = 1×2⁴ + 1×2³ + 0×2² + 0×2¹ + 1×2⁰
        = 16 + 8 + 0 + 0 + 1 = 25  => (25)₁₀ ✔

3) Decimal → Octal / Hex: Same tareeka, bas 8 ya 16 se divide karo. Example: (345)₁₀ → Octal = 531; (745)₁₀ → Hex = 2E9.

4) Binary → Octal (3-3 bits ka group, right se):

(11010110)₂  →  group: 011 | 010 | 110  →  3 | 2 | 6  => (326)₈ ✔

5) Binary → Hex (4-4 bits ka group):

(11001011)₂  →  group: 1100 | 1011  →  C | B  => (CB)₁₆ ✔

6) Octal/Hex → Binary: Ulta karo — har digit ko 3 (octal) ya 4 (hex) bits me kholo. (72)₈ = 111 010 = (111010)₂. (2F)₁₆ = 0010 1111.

Signed Numbers & 2's Complement important

Negative numbers represent karne ke 3 tarike hain: Sign-Magnitude (pehla bit sign: 0=+, 1=−), 1's Complement (saare bits ulto), 2's Complement (= 1's complement + 1). Computer 2's complement use karta hai kyunki isme subtraction ko addition se kar sakte hain.

(-5) ko 8-bit me kaise likhein?
 5  = 0000 0101
1's complement = 1111 1010
2's complement = 1111 1011   ✔  yahi hai (-5)

Check subtraction 7 − 5 using 2's complement:
  7  = 0000 0111
 -5  = 1111 1011  (2's complement form)
 ------------------
 sum = 1 0000 0010 → carry ko chhod do → 0000 0010 = 2 ✔ (7−5=2)

Related terms: BCD (Binary Coded Decimal — har decimal digit ko alag 4-bit: 29 = 0010 1001), ASCII (7-bit, 128 characters — 'A'=65), Extended ASCII (8-bit, 256), Unicode/UTF-8 (duniya ki saari languages + emoji 😀). Bit = 0 ya 1, Nibble = 4 bits, Byte = 8 bits.

Exam tip: Conversion ka question aaye to steps dikhana mandatory — sirf answer likhne se half marks. Aur 2's complement wala method table banake likho (upar wala style).

1.11 Planning a Computer Program — Algorithm, Flowchart, Pseudocode

Algorithm

An algorithm is a finite sequence of well-defined steps to solve a problem. (Writing code se pehle ki plan.)

Qualities (5): Finiteness (steps khatam hone chahiye), Definiteness (har step clear/unambiguous), Input (0 ya zyada), Output (kam se kam 1), Effectiveness (har step doable).

F-D-I-O-E = "FIDO Effectively" bhaunkta hai 🐶 — Finiteness, Input, Definiteness, Output, Effectiveness.

Examples (likh kar yaad karo):

Algo 1: Sum of two numbers
Step 1: Start
Step 2: Read A, B
Step 3: SUM = A + B
Step 4: Print SUM
Step 5: Stop

Algo 2: Largest of two numbers
Step 1: Start
Step 2: Read A, B
Step 3: If A > B then print "A is largest" else print "B is largest"
Step 4: Stop

Algo 3: Even / Odd
Step 1: Start
Step 2: Read N
Step 3: If (N mod 2 = 0) print "Even" else print "Odd"
Step 4: Stop

Algo 4: Factorial of N
Step 1: Start
Step 2: Read N
Step 3: F = 1, I = 1
Step 4: While I <= N repeat steps 5-6
Step 5:   F = F × I
Step 6:   I = I + 1
Step 7: Print F
Step 8: Stop

Algo 5: Average of 3 numbers
Step 1: Start
Step 2: Read A, B, C
Step 3: AVG = (A+B+C)/3
Step 4: Print AVG
Step 5: Stop

Pseudocode

Pseudocode is a way to write an algorithm using English-like statements mixed with programming keywords (IF, WHILE, PRINT) — kisi ek language ka strict syntax nahi hota.
BEGIN
    READ A, B
    IF A > B THEN
        PRINT "A is largest"
    ELSE
        PRINT "B is largest"
    END IF
END

BEGIN   // factorial
    READ N
    F = 1
    FOR I = 1 TO N DO
        F = F * I
    END FOR
    PRINT F
END

2.3 Central Processing Unit (CPU) — "Computer ka Dimaag"

The CPU is the brain of the computer; it executes instructions and controls the entire system. It has three parts: ALU, Control Unit (CU), and Registers. (On microcomputers, the CPU is contained in a single chip called a microprocessor.)

(a) ALU — Arithmetic Logic Unit

Do tarah ke operations karta hai: Arithmetic (+, −, ×, ÷, increment/decrement) aur Logical (comparisons >, <, =, AND/OR/NOT).

Real life: Jab aap calculator me 45+55 dalte ho to jo answer 100 aata hai wo ALU ne nikala. Aur jab Swiggy "coupon apply hua ya nahi" check karta hai (discount > 0 AND order > 199) — ye logical operation wo bhi ALU hi karta hai.

(b) CU — Control Unit

Poori machine ka traffic police 🚦. Nah khud calculate karta hai na store karta hai — bas instructions fetch karke decode karta hai aur doosre units ko command deta hai ki kya karna hai, kab karna hai.

Real life: Restaurant manager jaisa — khud khana nahi banata, par "chef ko order do, waiter ko table 5 pe le jao" — sab coordinate karta hai.

2.8 How CPU and Memory Work Together (program kaise chalta hai)

CPU teen step ka cycle repeat karta hai: Fetch → Decode → Execute (aur phir Store). Ise instruction cycle kehte hain, aur ye cycle ek clock (GHz) ke saath synchronise hota hai.

Instruction cycle (step-by-step):
1. FETCH   → PC batata hai agla instruction ka address → MAR me jata hai
             → memory se instruction aata hai → MDR → IR me late hai
2. DECODE  → CU instruction ko samajhta hai: "ye ADD karna hai"
3. EXECUTE → zarurat ka data ALU me jaata hai → calculation hota hai
4. STORE   → result ACC/register → phir RAM me likh diya jaata hai
             → PC +1 (agla instruction) → cycle repeat 🔁
Real-life walkthrough — c = a + b; (a=5, b=3 kya chal raha hai computer me):
  1. a aur b ki value RAM se registers me load hui (fetch)
  2. CU ne decode kiya: "add instruction"
  3. ALU ne 5 + 3 = 8 nikala (execute)
  4. Result 8 register me aaya, phir variable c ki memory location me store ho gaya (store)
  5. Agla instruction chala — screen pe print karna, to output device ko bhej diya
Isi ka naam "program execution" hai — aur ye cycle billions of times per second chalti hai. Insaan 1 second me 1 step sochta hai, CPU 1 second me ~3,00,00,00,000 cycles 😎

3.6 Booting

Booting is the process of starting (loading) a computer — jab power button dabate ho tab OS ko memory me load karke computer ko usable banane ki process.
Booting ke steps (exam me yahi likhna):
1. Power ON → SMPS sab parts ko current deta hai
2. POST (Power On Self Test) → BIOS/UEFI hardware check karta hai
   (RAM kitni hai, keyboard hai? galat ho to beep 🔔)
3. BIOS boot device dhundhta hai (HDD/SSD/USB/DVD)
4. Bootloader (GRUB/Windows Boot Manager) load hota hai

4.6 DML — Practical SQL (ye likhna seekho, exam me aata hai)

INSERT INTO student (roll_no, name, email, age, city, course_id)
VALUES (1, 'Ansh', 'ansh@mail.com', 19, 'Kichha', 101);

INSERT INTO student VALUES (2, 'Priya', 'priya@mail.com', 20, 'Haldwani', 102);

-- Fetch (kuch columns)
SELECT name, city FROM student;

-- Condition ke saath
SELECT * FROM student WHERE age >= 19 AND city = 'Kichha';

-- Sorting + limit
SELECT * FROM student ORDER BY name ASC LIMIT 10;

-- Aggregate (ganit wale functions)
SELECT COUNT(*), AVG(age), MAX(age), MIN(age) FROM student;
SELECT city, COUNT(*) FROM student GROUP BY city HAVING COUNT(*) > 5;

-- Update
UPDATE student SET city = 'Rudrapur' WHERE roll_no = 2;

-- Delete
DELETE FROM student WHERE roll_no = 2;

-- Do tables jodna (JOIN)
SELECT s.name, c.course_name
FROM student s JOIN course c ON s.course_id = c.course_id;
SQL keywords ka Hinglish meaning: SELECT = "kaunse columns dikhane hain", FROM = "kis table se", WHERE = "kis condition pe", ORDER BY = "kaise sort karna", GROUP BY = "kis cheez pe group banana", JOIN = "do tables jodna", HAVING = "group pe filter".

4.7 DCL & TCL

-- DCL (permission dena/lena)
GRANT SELECT, INSERT ON student TO user_ansh;
REVOKE INSERT ON student FROM user_ansh;

-- TCL (transaction control)
START TRANSACTION;
   UPDATE account SET balance = balance - 500 WHERE acc_no = 'A101';
   UPDATE account SET balance = balance + 500 WHERE acc_no = 'A102';
COMMIT;      -- dono update pakke ho gaye (permanent)
-- agar beech me error aa jaye to:
ROLLBACK;    -- dono update cancel (jaise kuch hua hi nahi)
Real life: UPI se ₹500 bhejna = do updates (ek account se minus, doosre me plus). Agar beech me bijli chali gayi — COMMIT nahi hua to ROLLBACK: paisa kahin nahi katega. 5.5 Web Basics — Introduction to Web

WWW (World Wide Web) is a collection of web pages and documents stored on web servers, linked together with hyperlinks, and accessed over the internet using a web browser. (Invented by Tim Berners-Lee in 1989–91 at CERN.)
Internet vs Web (classic confusion): Internet = hardware/infrastructure (computers ka network, roads 🛣️). Web = us network par chalne wali ek service (websites, ghar 🏠). Internet par email, FTP, WhatsApp bhi chalte hain — sirf web nahi. Web ⊂ Internet.

How a web page loads (request-response cycle)

1. Aap URL type karte ho → browser URL ko todta hai
   (protocol + domain + path)
2. DNS se IP address milta hai
3. Browser web server ko HTTP/HTTPS request bhejta hai (GET /index.html)
4. Server page (HTML/CSS/JS/images) response me bhejta hai
5. Browser HTML parse karta hai → page render karta hai (screen pe dikhta hai)

Web page (static vs dynamic): Static = fixed content, har user ko same (simple HTML — jaise college ka "About Us" page). Dynamic = content database se ban kar user ke hisaab se badalta hai (Amazon par aapka cart, Gmail inbox, Instagram feed).

5.6 Web Browser

A web browser is application software used to access, retrieve and display web pages from the internet.
  • Examples: Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, Opera, Brave.
  • Main parts: Address bar (URL), tabs, bookmarks, back/forward/reload buttons, history, extensions, developer tools (F12).
  • Kaam: HTML/CSS/JS ko padh kar page "render" karna, cookies/cache manage karna, security (HTTPS warning), downloads.
  • Search engine vs browser: Browser = car 🚗, Search engine = Google Maps 🗺️ (Chrome browser me Google search engine khulta hai — dono alag cheez hain! Ye exam me poochhte hain).

5.10 CSS (Cascading Style Sheets)

CSS is a style-sheet language used to control the appearance (design, colour, font, layout, spacing) of HTML web pages. "Cascade" ka matlab — ek hi element par kai rules lag sakte hain aur last/most-specific rule jeet jata hai.
Hinglish: HTML = kankad/pillar (dhancha), CSS = paint, tiles, curtains 🎨. Ek hi HTML ko alag-alag CSS se bilkul naya look de sakte ho — jaise ek hi ghar ko ek din shaadi wala sajaya jaaye, ek din simple.
<style>                                  /* CSS andar hi likh diya */

  .card { background: #fff; border-radius: 12px; padding: 16px; }
  #main-title { font-size: 32px; }
</style>

⚡ Unit 5 — Rapid Revision

  • Internet = network of networks • ARPANET 1969 • Protocol: TCP/IP • Web = internet ki ek service (Tim Berners-Lee, 1989)
  • Services: WWW, email, search, social media, e-commerce, UPI, cloud, VoIP, e-learning
  • Logical address = IP (badal sakta hai, DHCP deta hai, IPv4 32-bit / IPv6 128-bit) • Physical = MAC (permanent, 12 hex, NIC pe)
  • ISP = internet access provide karne wala (Jio, Airtel, BSNL) • Types: DSL, fibre, wireless, satellite
  • DNS = name → IP translation (internet ki phone directory) • Root → TLD → Authoritative server
  • Browser = page dikhata hai (Chrome) • Search engine = dhundhta hai (Google) — dono alag
  • HTTP (port 80, insecure) vs HTTPS (port 443, encrypted 🔒) • Methods: GET, POST, PUT, DELETE • 404 = not found
  • URL parts: protocol://domain:port/path?query#fragment
  • HTML = structure (tags), CSS = design (colours/fonts/layout), JS = behaviour
  • HTML5 special: audio/video tags, semantic tags (header/nav/section/footer)
