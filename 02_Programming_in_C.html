UNIT 1 — Introduction to C Programming

1.1 History of C

SaalKya hua
1960ALGOL 60 — C ka ancestor (structured programming ka idea)
1967BCPL (Basic Combined Programming Language) — Martin Richards
1970B language — Ken Thompson (Bell Labs)
1972C language — Dennis Ritchie (AT&T Bell Laboratories, USA) — UNIX OS ko dobara likhne ke liye banayi
1978"The C Programming Language" book (K&R C / Kernighan & Ritchie)
1989/1990ANSI C / C89 standard (standardization for portability)
1999, 2011C99, C11 — naye features
Yaad rakho: ALGOL → BCPL → B → C (har naam chhota hota gaya 😄) — aur ise banaya Dennis Ritchie ne 1972 me. "C" ka naam B se aaya (B ka next letter).
Real life: C ne "B language" ko replace kiya aur aaj bhi duniya ki sabse important language hai — Windows, Linux, Android ka core, MySQL, Python ka interpreter, aapki gaadi ka ECU — sab kisi na kisi hisse me C se bane hain. Isliye C ko "Mother of all Languages" kehte hain.

C kyun seekhna chahiye (features/importance)

  • Simple & powerful: sirf 32 keywords, lekin poora OS likh sakte ho
  • Middle-level language: high-level (samajhna easy) + low-level (memory/pointer control) dono ka mix
  • Portable: Ek baar likho, kisi bhi machine pe chalega (recompile karke)
  • Fast & efficient: Hardware ke bahut paas — isliye games ka core, OS, drivers C me
  • Structured language: Functions me todo, modular code
  • Rich library: hazaaron ready-made functions (math.h, string.h, stdio.h)
  • Base of everything: C++ , Java, JavaScript, PHP ka syntax bahut hadd tak C jaisa hai

1.2 Structure of a C Program

/* 1. Documentation section  — comments (naam, kaam, date) */
#include <stdio.h>        /* 2. Link/Library section — header files */
#define PI 3.14159        /* 3. Definition section — symbolic constants */

int add(int a, int b);    /* 4. Global declaration — function prototype */

int main()                /* 5. main() function — yahin se program shuru */
{
    int r;                /* 6. variable declaration */
    r = 5;

    printf("Area = %f\n", PI * r * r);
    return 0;             /* 0 = program successful khatam hua */
}

int add(int a, int b) {   /* 7. Sub-programs / user-defined functions */
    return a + b;
}

1.5 Declaration of Variables

A variable is a named memory location whose value can change during program execution. Declaration = compiler ko batana ki naam kya hai, type kya hai.
int a;                 // declaration
int b = 10;            // declaration + initialization (definition)
float pi = 3.14;
char grade = 'A';
int x = 5, y = 10;     // ek hi line me kai variables

Rules for naming variables (identifiers)

  1. Naam sirf letters (A–Z, a–z), digits (0–9) aur underscore (_) se banega.
  2. Pehla character letter ya underscore ho — digit nahi. ❌ 1num ✔️ num1
  3. Naam me space ya special symbol nahi (@, #, $, -). ❌ total marks
  4. Keyword naam nahi ho sakta. ❌ int int;
  5. C case-sensitive hai: marks aur Marks alag hain.
  6. Naam meaningful rakho (marks, total, avg) — debugging easy.

1.7 Symbolic Constants

Value jo program me change nahi hoti aur naam ke saath define ki jaati hai. C me 3 tarike: #define (preprocessor), const (keyword), enum (list of integer constants).
// 1. #define (macro) — text replace (preprocessor karta hai)
#define PI 3.14159
#define MAX 100
#define MSG "Welcome"

// 2. const keyword — type-safe constant (memory me jagah leta hai)
const float GST = 0.18;

// 3. enum — named integer constants
enum week { MON, TUE, WED };   // MON=0, TUE=1, WED=2
Real life: Tax rate, PI, max students, GST — ye values program me kahin-kahin use hoti hain. Agar hard-code (0.18 har jagah) kar do aur rate badal jaaye, poori file edit karni padegi. Symbolic constant use karo: sirf ek jagah badlo, sab jagah apply. ✅

1.8 Storage Classes Exam favourite ⭐

A storage class defines the scope (kahan tak naam chalta hai), lifetime (kab tak memory me rehta hai), initial value (default) aur memory location (RAM ya register) of a variable. C me 4 storage classes hain: auto, register, static, extern.

registerregisterSirf us block ke andarBlock khatam = freeGarbageCPU register (agar possible ho) — fastest

Hinglish: auto = "aaj ka guest" 🚪 (kaam khatam, banda gaya). static = "wo diary jo har saal wahi cheez yaad rakhti hai" 📔 (value zinda rehti hai). register = "haath me pakdi cheez" ✋ (sabse tez access, CPU ke jeb me). extern = "poore mohalle ka common naam" (global — kisi doosri file me bhi use ho sakta hai).
/* static ka jaadu — count hota rehta hai, reset NAHI hota */
#include <stdio.h>
void counter() {
    static int c = 0;      // sirf pehli baar 0 hota hai!
    c++;
    printf("Called %d times\n", c);
}
int main() {
    counter();  // Called 1 times
    counter();  // Called 2 times
    counter();  // Called 3 times
    return 0;
}
Exam Q yaad rakho: "static variable ki value function calls ke beech kaise survive karti hai?" — Kyunki static variable RAM me program ke poore lifetime ke liye banta hai (stack pe nahi), sirf ek baar initialize hota hai. Yahi wala program likh dena = full marks ✅

UNIT 2 — C Operators & Expressions

2.1 What is an Operator & Expression?

Operator: A symbol that performs an operation on values (operands). Expression: A combination of operands (variables/constants) and operators that produces a value. Example: c = a + b — yahan + operator hai, (a+b) expression hai, c result store karta hai.

% ka real-life use: Even/odd check (n % 2 == 0), "har 3rd student ki fee" (roll % 3 == 0), clock ka seconds (total % 60), circular seats (chair number = position % total_chairs).

UNIT 3 — Control Structures

Control structures program ke execution ka flow (rasi) control karte hain. C me 3 types: Sequence (line-by-line), Selection/Decision (if, switch — condition ke hisaab se raasta), Iteration/Loop (while, do-while, for — kaam baar-baar). Aur jump statements (break, continue, goto) jo flow ko todte hain.
Real life analogy (ghar chhod kar college Jana 🎒): Subah uthte hi sequence (utho → brush karo → nashta → niklo). Raaste me if-else: "Agar barish hai to raincoat pehno warna nahi." Gate par while loop: "Jab tak auto nahi aata, wait karo." Lecture ke beech break: "Sir ne attendance li, nikal gaye." Ye poora din hi program ki tarah hai 😄

3.5 Switch Statement

switch is a multi-way decision statement that compares one expression's value against several case values, and jumps to the matching case. Har case ke end me break lagana zaroori hai (warna "fall through" — neeche ke cases bhi chal jaate hain).
switch (expression) {           // int/char ho sakta hai — float nahi!
    case value1:
        statements;
        break;
    case value2:
        statements;
        break;
    default:                    // koi case match nahi hua
        statements;
}

// Example: simple calculator
switch (op) {
    case '+': printf("%f", a + b); break;
    case '-': printf("%f", a - b); break;
    case '*': printf("%f", a * b); break;
    case '/': printf("%f", a / b); break;
    default : printf("Invalid operator");
}
Real life: Restaurant ka menu = switch! Customer "1 dabaye" → Pizza case, "2 dabaye" → Burger case, warna → "Invalid option". ATM ke buttons bhi yahi hote hain (1 = Balance, 2 = Withdraw, 3 = Mini statement).

2D array ki memory representation (Row-Major Order)

int m[2][3] = { {1,2,3}, {4,5,6} };   (int = 4 bytes, base = 2000)

Memory me linear (ek seedhi line me) rakhta hai — ROW by ROW:
[1][2][3][4][5][6]
2000 2004 2008 2012 2016 2020

Address formula: addr(m[i][j]) = Base + (i × cols + j) × size
  m[1][2] = 2000 + (1×3 + 2) × 4 = 2000 + 20 = 2020 ✔

⚠️ Column-major order (FORTRAN) me pehle column bhar jata hai — C me row-major hota hai.

5.4 Parameter Passing: Call by Value vs Call by Reference Exam favourite ⭐

/* LAB #10 — Call by value vs Call by reference (swap example) */
#include <stdio.h>

// ---- CALL BY VALUE: original nahi badlega ----
void swapVal(int x, int y) {
    int t = x;  x = y;  y = t;    // sirf copies badli
}

// ---- CALL BY REFERENCE: original BADLEGA ----
void swapRef(int *x, int *y) {
    int t = *x;  *x = *y;  *y = t;   // address wali value badli
}

int main() {
    int a = 10, b = 20;

    swapVal(a, b);
    printf("After call by value:     a=%d b=%d\n", a, b);
    // a=10 b=20  ← kuch nahi badla!

    swapRef(&a, &b);
    printf("After call by reference: a=%d b=%d\n", a, b);
    // a=20 b=10  ← original badal gaya ✔

    return 0;
}
Yaad rakhne ka tareeka: Call by value = photocopy dena 📄 (aapke original document pe koi asar nahi). Call by reference = original file ka pata dena 🏠 (jo bhi usse badlega, aapke ghar me hi badlega).

5.5 Recursion

A recursive function is a function that calls itself to solve a smaller version of the same problem. Har recursion me ek base case (rukne ki condition) hona zaroori hai — warna infinite recursion = stack overflow 💥
/* Factorial — recursion se (lab: GCD bhi isi tarah) */
#include <stdio.h>

long factorial(int n) {
    if (n == 0 || n == 1)
        return 1;                    // BASE CASE (ruko!)
    else
        return n * factorial(n - 1); // khud ko chhote input se call
}

int main() {
    printf("%ld", factorial(5));     // 120
    return 0;
}

/* Andar kya hua: factorial(5)
   = 5 * factorial(4)
   = 5 * 4 * factorial(3)
   = 5 * 4 * 3 * factorial(2)
   = 5 * 4 * 3 * 2 * factorial(1)
   = 5 * 4 * 3 * 2 * 1 = 120  ✔  */
/* LAB #8 — GCD by iteration AND recursion */
int gcdIter(int a, int b) {          // loop wala
    while (b != 0) {
        int t = b;
        b = a % b;
        a = t;
    }
    return a;
}

int gcdRec(int a, int b) {           // recursion wala (Euclid)
    if (b == 0) return a;
    return gcdRec(b, a % b);
}
Recursion ✔️Recursion ✘ (vs Iteration)
Code chhota aur math ke paas (tree, factorial, Fibonacci, Tower of Hanoi)Har call me memory (stack) kharch hoti hai
Kuch problems sirf recursion se hi saaf likhi jaati hainBina base case = stack overflow / infinite loop
Elegant, padhne me easyIteration aksar zyada fast hota hai (function call ka overhead)
Real life: Recursion = "office ka kaam aage pass karna" 📋. Boss ne kaam diya → assistant ko diya → assistant ne intern ko diya → intern sabse chhota kaam khud kar leta hai (base case) → result wapas chain me upar aata hai. Google Drive me folders ke andar folders dhundhna — wahi recursion hai.

5.6 Understanding Pointers

A pointer is a variable that stores the memory address of another variable (instead of storing a value). Isse computer ka memory directly access/control hota hai — yeh C ki sabse powerful (aur thoda dangerous 😈) feature hai.
Hinglish: Normal variable = ghar 🏠 (usme rehne wala). Pointer = us ghar ka address likha hua parcha 📮. Address ke paas jaake aap ghar me kya hai dekh sakte ho (value padho) ya badal bhi sakte ho (value likho). Isliye pointer ko "address wala variable" kehte hain.
/* Pointer declaration, initialization & use */
#include <stdio.h>
int main() {
    int a = 10;          // ek normal variable
    int *p;              // pointer declaration (int ka pointer)

    p = &a;              // p me a ka ADDRESS daala (& = address-of)

    printf("Value of a      = %d\n", a);     // 10
    printf("Address of a    = %p\n", &a);    // e.g. 0061FF1C
    printf("p me kya hai    = %p\n", p);     // same address!
    printf("a ki value via p= %d\n", *p);    // 10 (* = dereference)

    *p = 50;             // pointer se a ki value badal di
    printf("Ab a = %d\n", a);                // 50 ✔
    return 0;
}
Symbol / TermMatlab
& (address-of operator)Variable ka address nikalta hai: &a
* (dereference / indirection operator)Address par padi value: *p (padhna ya likhna dono)
int *pDeclaration — "p ek pointer hai jo int address rakhega"
NULL pointerint *p = NULL; — kisi address pe nahi (safe practice)
Safety rules (nahi to crash 💥): (1) Bina initialize pointer dereference mat karo (int *p; *p = 5; ❌). (2) NULL check karo. (3) Function se local variable ka address return mat karo (wo variable function ke baad mar jata hai). Ye "dangling pointer" aur "segmentation fault" ka source hote hain.

5.7 Pointers and Arrays (dono bhai-bhai hain)

int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;          // arr khud pehle element ka address hai!

// Ye chaaro lines same kaam karti hain:
arr[2]  ==  *(arr + 2)  ==  *(p + 2)  ==  p[2]   // sab = 30 ✔

// &arr[0] == arr  (base address)  — exam me aata hai

// Loop with pointer (array ka alternative tarika)
for (i = 0; i < 5; i++)
    printf("%d ", *(p + i));
Kyun important hai: C me array ka naam hi uske pehle element ka pointer hai. Isi liye jab function ko array bhejte ho, to "call by reference" ho jaata hai (original array hi modify hota hai) — bina & ke. Isliye void update(int a[]) me jo badla, wapas main me bhi badla hua milta hai.

5.8 Pointer Arithmetic

int arr[5] = {10,20,30,40,50};
int *p = arr;      // address 1000 maan lo

p++;        // agle element pe — address +4 (int ke size jitna!) → 1004 → value 20
p--;        // pichle element pe → 1000
p + 2;      // 2 element aage → 1008 → value 30
p - 1;      // ek peeche
p2 - p1;    // do pointers ke beech ka difference = kitne elements ka gap
Rule yaad rakho: p++ ka matlab "1 byte aage" nahi hai — matlab "1 ELEMENT aage" (int me 4 bytes, char me 1 byte). Compiler khud type ka size lagata hai. Isliye char* ka p++ = 1 byte, int* ka p++ = 4 bytes. 🎯

5.10 Pointer + Function = Call by Reference (poore lab ka favourite)

/* Function jo do numbers ko pointer se update karta hai */
#include <stdio.h>

void minMax(int arr[], int n, int *mn, int *mx) {
    int i;
    *mn = *mx = arr[0];
    for (i = 1; i < n; i++) {
        if (arr[i] < *mn) *mn = arr[i];
        if (arr[i] > *mx) *mx = arr[i];
    }
}

int main() {
    int a[6] = {45, 12, 78, 3, 90, 56};
    int small, big;

    minMax(a, 6, &small, &big);   // addresses bheje
    printf("Smallest = %d, Largest = %d", small, big);
    // Output: Smallest = 3, Largest = 90 ✔
    return 0;
}
Exam tip (bahut common question): "Ek function se do values kaise return karein?" — C me return sirf ek value deta hai, par pointers (call by reference) se aap 2, 3, jitni chaho values modify/return kar sakte ho. Yahi answer example ke saath likhna = full marks.
