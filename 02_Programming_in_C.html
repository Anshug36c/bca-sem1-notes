1.1 History of C

C ek general-purpose, procedural (structured) programming language hai jise Dennis Ritchie ne 1972 me AT&T Bell Laboratories, USA me develop kiya. Iska main maksad tha — UNIX operating system ko dobara likhna. C apne se pehle aayi B language ka successor hai (isliye naam "C" — B ke agla letter), aur B khud BCPL se aayi thi.

1.2 Structure of a C Program

Har C program ek fixed dhaanche (structure) me likha jaata hai — comments se shuru, phir header files, symbolic constants, global declarations, aur phir main() function (jahan se program chalta hai), aur akhir me user-defined functions. Exam me ye 6–7 sections yaad rakhna zaroori hai.
/* 1. Documentation section — comments (naam, kaam, date) */
#include <stdio.h>        /* 2. Link/Library section — header files */
#define PI 3.14159        /* 3. Definition section — symbolic constants */
int add(int a, int b);    /* 4. Global declaration — function prototype */
int main()                /* 5. main() function — yahin se program shuru */
{
    int r;                /* 6. variable declaration */
    r = 5;
    printf("Area = %f\n", PI * r * r);
    return 0;             /* 0 = program successful khatam hua */
}
int add(int a, int b) {   /* 7. Sub-programs / user-defined functions */
    return a + b;
}

A data type tells the compiler what kind of value a variable will store (number, character, decimal) and how much memory it needs. C strongly typed hai — har variable ka type pehle se batana padta hai, isliye memory ka control poore programmer ke haath me hota hai.

Size kaise pata karein? printf("%d", sizeof(int)); → 4 (ya 2). sizeof ek operator hai (function nahi) jo kisi bhi type/variable ka size bytes me batata hai. Yaad rakho: size machine/compiler par depend karta hai — Turbo C (16-bit) me int 2 byte hota hai, gcc (64-bit) me 4 byte. Isi liye portability ke liye sizeof use karna best practice hai. 🧮
Overflow ka concept (MCQ me aata hai): Har type ki ek limit hai. char me 127 ke baad value 128 nahi, −128 ho jaati hai (wrap around). unsigned char me 255 ke baad 0. Isi tarah 2-byte int me 32,767 ke baad −32,768. Bade numbers ke liye long long use karo — jaise 20! = 2,432,902,008,176,640,000 jo int me fit hi nahi hota. 🔁

1.5 Declaration of Variables

A variable is a named memory location whose value can change during program execution. Declaration = compiler ko batana ki naam kya hai, type kya hai (jagah reserve karna). Initialization = pehli value dena. Definition = declaration + memory allotment (C me aam taur par dono ek hi likhte hain).
// Declaration
int a;
// Declaration + initialization (definition)
int b = 10;
float pi = 3.14;
char grade = 'A';
int x = 5, y = 10;   // ek hi line me kai variables

// Galat tarike (exam me "identify the error" ke liye):
// int 1num = 5;        // digit se naam shuru nahi hota
// int total marks = 5; // space allowed nahi
// int int = 5;         // keyword naam nahi ban sakta

Rules for naming variables (identifiers)

  • Naam sirf letters (A–Z, a–z), digits (0–9) aur underscore (_) se banega.
  • Pehla character letter ya underscore ho — digit nahi. ❌ 1num ✔️ num1
  • Naam me space ya special symbol nahi (@, #, $, -). ❌ total marks
  • Keyword naam nahi ho sakta. ❌ int int;
  • C case-sensitive hai: marks aur Marks alag hain.
  • Naam meaningful rakho (marks, total, avg) — debugging easy.
  • Maximum length compiler par depend karti hai, par 31 characters tak ka naam har jagah chal jaata hai.

Hinglish: auto = "aaj ka guest" 🚪 (kaam khatam, banda gaya). static = "wo diary jo har saal wahi cheez yaad rakhti hai" 📔 (value zinda rehti hai). register = "haath me pakdi cheez" ✋ (sabse tez access, CPU ke jeb me). extern = "poore mohalle ka common naam" (global — kisi doosri file me bhi use ho sakta hai).
/* static ka jaadu — count hota rehta hai, reset NAHI hota */
#include <stdio.h>
void counter() {
    static int c = 0;      // sirf pehli baar 0 hota hai!
    c++;
    printf("Called %d times\n", c);
}
int main() {
    counter();             // Called 1 times
    counter();             // Called 2 times
    counter();             // Called 3 times
    return 0;
}
/* Default values ka demo — local garbage vs static/global zero */
#include <stdio.h>
int g;                     // global — default 0
void test() {
    int local;             // auto — garbage value (kuch bhi!)
    static int s;          // static — default 0
    printf("local=%d  static=%d  global=%d\n", local, s, g);
}
int main() { test(); return 0; }
/* Output (local garbage ho sakti hai, static/global pakka 0):
   local=32767  static=0  global=0 */

2.8 Conditional (Ternary) Operator

Ye C ka ekmatra 3-operand operator hai (isliye "ternary"). Syntax: condition ? value_if_true : value_if_false. Ye chhote if-else ka short form hai aur direct expression me value deta hai — isliye ise "inline if-else" kehte hain.
// Syntax
result = (condition) ? value_true : value_false;

// Example: dono me se bada number
int a = 10, b = 25, big;
big = (a > b) ? a : b;         // big = 25

// Nested ternary: teen me se bada
big = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);

// Same cheez if-else me (kitna lamba hai, dekho 👇)
if (a > b) big = a; else big = b;
/* Program: ternary ke 3 classic uses */
#include <stdio.h>
int main() {
    int a = 15, b = 8, c = 30, marks = 40;

    /* 1. Bada number */
    printf("Bigger = %d\n", (a > b) ? a : b);          // 15

    /* 2. Pass/Fail — statement me bhi */
    printf("Result: %s\n", (marks >= 33) ? "PASS" : "FAIL");  // PASS

    /* 3. Even/Odd */
    printf("%d is %s\n", a, (a % 2 == 0) ? "Even" : "Odd");   // Odd

    /* 4. Teen me se bada (nested) */
    printf("Largest of three = %d\n", (a>b) ? ((a>c)?a:c) : ((b>c)?b:c));  // 30
    return 0;
}

2.10 Operator Precedence & Associativity Exam favourite ⭐

Precedence: Jab ek expression me kai operators hon, to kaun pehle chalega — iska order. Associativity: Same precedence wale operators me kaun pehle — left-to-right (L→R) ya right-to-left (R→L). Example: 2 + 3 * 4 = 14 (kyunki * ki precedence + se zyada hai), aur 10 − 3 − 2 = 5 (L→R associativity).

4.1 Array — Introduction

An array is a collection of a fixed number of elements of the same data type, stored in contiguous (continuous) memory locations and accessed using a common name with an index. C me index 0 se shuru hota hai — pehla element a[0], aakhri a[n-1].
Hinglish: Array = ek hi type ki cheezon ki "trey" 🍽️ — jaise ek thali me rakhi 10 rotis, ya ek row me baithhe 60 students. Naam sirf ek (marks), par har element ka apna number/index (marks[0], marks[1], …). Bina array ke 60 students ke liye 60 variables banane padte 😱 — array ne zindagi aasan kar di.

Array ki characteristics (5 points — ratt lo)

  1. Same type: sab elements ka data type ek hi (int array me sirf ints, float me floats). Mix nahi kar sakte.
  2. Contiguous memory: elements RAM me lagataar (ek ke baad ek) rakhte hain — isliye address formula kaam karta hai.
  3. Fixed size: size declare karte waqt batana padta hai; program chalte waqt badha nahi sakte.
  4. Index 0 se: pehla element index 0, last index = size − 1. Size 5 → valid indexes 0,1,2,3,4.
  5. Ek naam, kai values: array ka naam base address ko represent karta hai (array ka naam hi pehle element ka pointer hai — Unit 5 me detail me).

4.2 One-Dimensional Array

1D array = ek single line/row me values. Sabse simple aur sabse zyada use hone wala array. Iske 3 kaam yaad rakho: declare karo, initialize karo, loop se access karo.
/* 1) DECLARATION (kitne elements chahiye) */
int marks[60];          // 60 ints (index 0..59)
float price[5];
char grade[10];

/* 2) INITIALIZATION — 4 tarike */
int a[5] = {10, 20, 30, 40, 50};   // poora
int b[5] = {10, 20};               // baaki 3 automatically 0
int c[]  = {5, 10, 15};            // size compiler count karega (3)
int d[5] = {0};                    // saare 5 elements 0 (reset ka trick!)

/* 3) ACCESS (index 0 se shuru!) */
a[0] = 10;              // pehla element
a[4] = 50;              // 5th (aakhri) element
a[5] = 99;              // ❌ OUT OF BOUNDS — undefined behaviour (garbage/crash!)

/* 4) LOOP se input + output (classic pattern) */
for (i = 0; i < 5; i++)
    scanf("%d", &marks[i]);
for (i = 0; i < 5; i++)
    printf("%d ", marks[i]);
Bounds ka dhyaan: C arrays par koi bounds checking nahi karta (Python/Java me error aata hai, C me nahi!). int a[5] me a[5] ya a[-1] likhne par compiler kuch nahi kahega, par program garbage value dega ya crash — is bug ko pakadna bahut mushkil hota hai. Isliye loop hamesha i < n par roko (kabhi i <= n nahi!). Ye "off-by-one error" exam me hi nahi, real jobs me bhi famous galti hai. ⚠️

Memory Representation (exam me poochhte hain — address calculation)

int a[5] = {10, 20, 30, 40, 50};   (assume int = 4 bytes, base address 1000)

Index    :  a[0]   a[1]   a[2]   a[3]   a[4]
Value    :   10     20     30     40     50
Address  :  1000   1004   1008   1012   1016
             ↑ Base address (a == &a[0])

FORMULA:  Address of a[i] = Base_Address + (i × size_of_one_element)

Verification:
  a[0] → 1000 + (0 × 4) = 1000 ✔
  a[3] → 1000 + (3 × 4) = 1012 ✔
  a[4] → 1000 + (4 × 4) = 1016 ✔ (aakhri element)

Exam question: "int a[10]; base address 2000 hai, a[6] ka address kya hoga?"
Answer: 2000 + (6 × 4) = 2024.

Aur ye formula hi ARRAY KA SABSE BADA PLUS hai — O(1) random access:
1000th element bhi utni hi speed se milta hai jitni 1st (formula se seedha address).
Real life analogy: Library me ek shelf pe saari kitaabein serial-wise lagao (array) vs alag-alag kamron me rakho (linked list). Shelf me "7th kitaab" ka address formula se turant pata (base + 6 × size), par beech me nayi kitaab daalni ho to saari khiskaani padegi — bilkul array ke insert/delete ki tarah 📚

4.3 Two-Dimensional Array (matrix / table)

A 2D array is a collection of elements arranged in rows and columns (table/matrix). Declaration: type name[rows][columns]; — pehla index row, doosra column. int m[3][4] = 3 rows, 4 columns = 12 elements. Input/output ke liye nested loops chahiye (bahar row, andar column).
/* Declaration aur initialization ke 3 tarike */

int m[2][3] = { {1, 2, 3},                    // nested braces (clear)
                {4, 5, 6} };
int m2[2][3] = {1, 2, 3, 4, 5, 6};            // flat — same cheez (row-by-row)
int m3[2][3] = { {1, 2}, {4} };               // baaki cells 0 ho jaati hain

/* Access: m[row][column] — dono index 0 se */
m[0][0] = 1;      // pehli row, pehla column
m[1][2] = 6;      // doosri row, teesra column (aakhri element)

/* Input / Output — nested loops (billing loops zaroori!) */
for (i = 0; i < rows; i++) {          // outer = row
    for (j = 0; j < cols; j++) {      // inner = column
        scanf("%d", &m[i][j]);
    }
}
for (i = 0; i < rows; i++) {
    for (j = 0; j < cols; j++) {
        printf("%4d", m[i][j]);       // row me print — %4d se alignment
    }
    printf("\n");                      // har row ke baad newline
}

2D array ki memory representation (Row-Major Order) — exam favourite

int m[2][3] = { {1,2,3}, {4,5,6} };   (int = 4 bytes, base = 2000)

C memory me 2D array ko LINEAR (ek seedhi line me) rakhta hai — ROW by ROW:

  [1]   [2]   [3]   [4]   [5]   [6]
  2000  2004  2008  2012  2016  2020
  ←── row 0 ──→     ←── row 1 ──→

ADDRESS FORMULA:  addr(m[i][j]) = Base + ( (i × number_of_columns) + j ) × size

Verification:
  m[0][2] → 2000 + ((0×3) + 2) × 4 = 2000 + 8  = 2008 ✔ (row 0 ka teesra)
  m[1][0] → 2000 + ((1×3) + 0) × 4 = 2000 + 12 = 2012 ✔ (row 1 ka pehla)
  m[1][2] → 2000 + ((1×3) + 2) × 4 = 2000 + 20 = 2020 ✔ (aakhri element)

⚠️ C me ROW-MAJOR order hota hai (pehle row bhar jati hai).
   COLUMN-MAJOR order (FORTRAN) me pehle column bhar jata hai — MCQ me aata hai!

5.4 Parameter Passing: Call by Value vs Call by Reference Exam favourite ⭐

Call by value: function ko variable ki value ki copy jaati hai — function andar jo badle, original par asar nahi. Call by reference: function ko variable ka address (pointer) jaata hai — function usi original memory par kaam karta hai, isliye original value badal jaati hai.
MEMORY PICTURE (call by value) — sirf copy jaati hai:

  main() me:  a = 10, b = 20           swapVal(x, y) me:
                                        x = 10, y = 20   ← ALAG copies
  Function khatam → copies gayab →  a = 10, b = 20 (unchanged!)

MEMORY PICTURE (call by reference) — address jaata hai:

  main() me:        a = 10   (address 1000)
                    b = 20   (address 1004)
                              ↑        swapRef(&a, &b) me:
                              └──────  x = 1000, y = 1004 (addresses)
  *x = 20 karne se  → a (jo 1000 par hai) ki value badal gayi!
  Function khatam → a = 20, b = 10 ✔ (original badla)

#include <stdio.h>

/* ---- CALL BY VALUE: original nahi badlega ---- */
void swapVal(int x, int y) {
    int t = x; x = y; y = t;        // sirf copies badli
}

/* ---- CALL BY REFERENCE: original BADLEGA ---- */
void swapRef(int *x, int *y) {
    int t = *x;                      // * = us address ki value
    *x = *y;
    *y = t;                          // original memory badli
}

int main() {
    int a = 10, b = 20;
    swapVal(a, b);
    printf("After call by value: a=%d b=%d\n", a, b);      // a=10 b=20
    swapRef(&a, &b);
    printf("After call by reference: a=%d b=%d\n", a, b);   // a=20 b=10 ✔
    return 0;
}

   After call by reference: a=20 b=10  ← original badal gaya ✔ */

5.5 Recursion

A recursive function is a function that calls itself to solve a smaller version of the same problem. Har recursion me ek base case (rukne ki condition) hona zaroori hai — warna infinite recursion aur stack overflow 💥. Recursive solutions math problems (factorial, Fibonacci, GCD, Tower of Hanoi) ke liye bahut elegant hote hain.
/* Factorial — recursion se (lab: GCD bhi isi tarah) */
#include <stdio.h>
long factorial(int n) {
    if (n == 0 || n == 1)
        return 1;                  // BASE CASE (ruko!)
    else
        return n * factorial(n - 1);   // khud ko chhote input se call
}
int main() {
    printf("5! = %ld\n", factorial(5));   // 120
    return 0;
}
/* Andar kya hua (recursion ka tree):
   factorial(5) = 5 * factorial(4)
                = 5 * 4 * factorial(3)
                = 5 * 4 * 3 * factorial(2)
                = 5 * 4 * 3 * 2 * factorial(1)
                = 5 * 4 * 3 * 2 * 1
                = 120 ✔ (base case par ruk kar sab multiply hua) */
/* Program: Fibonacci ka n-th term by recursion (2 calls — recursion tree) */
int fib(int n) {
    if (n == 0) return 0;          // base
    if (n == 1) return 1;          // base
    return fib(n - 1) + fib(n - 2);  // do recursive calls!
}
/* fib(6) = fib(5) + fib(4) = 5 + 3 = 8
   Note: yahan calls ki ginti exponential hoti hai — fib(40) dheere chalega.
   Isliye iteration wala version fast hota hai (recursion vs iteration ka point!) */

/* LAB #8 — GCD by iteration AND recursion */
int gcdIter(int a, int b) {          // loop wala
    while (b != 0) {
        int t = b;
        b = a % b;
        a = t;
    }
    return a;
}
int gcdRec(int a, int b) {            // recursion wala (Euclid)
    if (b == 0) return a;             // base case
    return gcdRec(b, a % b);          // chhote problem par pass
}
/* gcdRec(48, 18) → gcdRec(18, 12) → gcdRec(12, 6) → gcdRec(6, 0) → 6 ✔ */

/* Program: sum of digits by recursion (n%10 nikalo, n/10 par call) */
int digitSum(int n) {
    if (n == 0) return 0;
    return (n % 10) + digitSum(n / 10);
}
/* digitSum(4821) = 1 + digitSum(482) = 1 + 2 + digitSum(48) = 1+2+8+digitSum(4) = 1+2+8+4 = 15 ✔ */

/* Program: x^n by recursion (power) */
int power(int x, int n) {
    if (n == 0) return 1;              // kuch bhi ^ 0 = 1
    return x * power(x, n - 1);
}
/* power(2, 5) = 2 × 2 × 2 × 2 × 2 = 32 ✔ */

5.6 Understanding Pointers

A pointer is a variable that stores the memory address of another variable (value ki jagah address). Isse memory ko directly access/control kiya jaata hai — yeh C ki sabse powerful (aur thoda dangerous 😈) feature hai, aur C ko "middle-level language" banata hai.
Hinglish: Normal variable = ghar 🏠 (usme rehne wala). Pointer = us ghar ka address likha hua parcha 📮. Address ke paas jaake aap ghar me kya hai dekh sakte ho (value padho) ya badal bhi sakte ho (value likho). Isliye pointer ko "address wala variable" kehte hain.
/* Pointer declaration, initialization & use — poora program */
#include <stdio.h>
int main() {
    int a = 10;                // ek normal variable
    int *p;                    // pointer declaration (int ka pointer)

    p = &a;                    // p me a ka ADDRESS daala (& = address-of)

    printf("Value of a     = %d\n", a);      // 10
    printf("Address of a   = %p\n", &a);     // e.g. 0061FF1C
    printf("p me kya hai   = %p\n", p);      // wahi address!
    printf("a ki value via p = %d\n", *p);   // 10 (* = dereference)

    *p = 50;                   // pointer se a ki value badal di
    printf("Ab a = %d\n", a);                // 50 ✔
    return 0;
}
/* Yaad rakho: p = address rakhta hai, *p = us address par padi VALUE
   a  aur  *p  ek hi jagah hain — ek ko badla, doosra bhi badla! */

5.7 Pointers and Arrays (dono bhai-bhai hain)

C me array ka naam uske pehle element ka pointer hai — arr == &arr[0]. Aur arr[i] likhna aur *(arr + i) likhna bilkul same cheez hai (compiler andar se arr[i] ko *(arr+i) hi convert karta hai). Isi wajah se function me array bhejna = call by reference banana.
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;              // arr khud pehle element ka address hai!

/* Ye chaaro lines SAME cheez tak le jaati hain: */
arr[2]  ==  *(arr + 2)  ==  *(p + 2)  ==  p[2]     // sab = 30 ✔
 &arr[0] ==  arr  ==  p                            // base address
 &arr[2] ==  (arr + 2) == (p + 2)                  // teesre element ka address

/* Loop with pointer (array ka alternative tarika) */
for (i = 0; i < 5; i++)
    printf("%d ", *(p + i));         // 10 20 30 40 50

/* Array ko function me bhejna = call by reference (bina & ke!) */
#include <stdio.h>
void doubleAll(int a[], int n) {      // a[] as good as int *a
    int i;
    for (i = 0; i < n; i++)
        a[i] = a[i] * 2;              // ORIGINAL array hi badla
}
int main() {
    int x[4] = {1, 2, 3, 4}, i;
    doubleAll(x, 4);
    for (i = 0; i < 4; i++) printf("%d ", x[i]);   // 2 4 6 8 ✔
    return 0;
}
Yaad rakho: arr[i] = *(arr + i) = *(p + i) = p[i] — exam me ye chaar roop ek saath likh kar dikhana, examiner ka favourite point hai. Aur &arr[i] = arr + i • sizeof(arr) = poore array ka size, lekin sizeof(p) sirf pointer ka 8 byte — array aur pointer ka farak yahi hai (array ka size pata hota hai, pointer ka nahi). 🎯

5.8 Pointer Arithmetic

Pointer par ++, --, + n, - n, aur do pointers ka difference — ye sab allowed hai. Rule: pointer ± n = n ELEMENTS aage/peeche — compiler khud type ka size (int = 4, char = 1) multiply kar deta hai. Ye n ka "n bytes nahi, n elements hai" wala point hi poore concept ka nichod hai.
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;                  // maan lo address = 1000

p++;      // agle ELEMENT par — address 1000 → 1004 (+4, int ke size jitna) → *p = 20
p--;      // pichle element par → 1004 → 1000 → *p = 10
p = p + 2;  // do element aage → 1008 → *p = 30
p = p - 1;  // ek peeche → 1004 → *p = 20

int *q = &arr[4];   // address 1016
q - p;              // do pointers ka difference = kitne ELEMENTS ka gap (bytes ka nahi!)
                    // 1016 - 1004 = 12 bytes ÷ 4 = 3 elements

/* char pointer me farak dekho */
char s[] = "BCA";
char *c = s;        // address 2000
c++;                // 2001 (+1 byte, char ke size jitna) → *c = 'C'

/* Comparison allowed hai */
if (p < q) printf("p pehle wale element par hai\n");   // addresses ki comparison
/* Program: pointer arithmetic se array traverse (dono loop style) */
#include <stdio.h>
int main() {
    int a[5] = {10, 20, 30, 40, 50};
    int *p = a, sum = 0;

    while (p < a + 5) {        // jab tak aakhri element tak na pahuncho
        sum += *p;
        p++;
    }
    printf("Sum = %d\n", sum);   // Sum = 150

    p = a;                        // reset
    for (int i = 0; i < 5; i++)
        printf("%d ", *(p + i));  // 10 20 30 40 50
    return 0;
}
Rule yaad rakho: p++ ka matlab "1 byte aage" nahi hai — matlab "1 ELEMENT aage" (int me 4 bytes, char me 1 byte, float me 4 bytes, double me 8 bytes). Compiler khud type ka size lagata hai. Isliye char* ka p++ = 1 byte, int* ka p++ = 4 bytes. Aur ek MCQ favourite: do pointers ko jodna/nikalna — p1 + p2 ❌ invalid, p1 - p2 ✔ valid (elements ka difference deta hai). 🎯

5.10 Pointer + Function = Call by Reference (poore lab ka favourite)

Jab function ko variable ka address (pointer) bhejte hain, to function us original memory par kaam karta hai — isse ek function se kai values "wapas" mil sakti hain (jaise min + max, sum + average) aur swap/update jaisa kaam ho jaata hai. C ka return sirf ek value deta hai, par pointers ki madad se hum 2, 3, jitni chahiye values modify kar sakte hain.
/* Program: function jo ek array ke min AUR max dono return kare (pointers se) */
#include <stdio.h>
void minMax(int arr[], int n, int *mn, int *mx) {
    int i;
    *mn = *mx = arr[0];              // pehle element se start
    for (i = 1; i < n; i++) {
        if (arr[i] < *mn) *mn = arr[i];
        if (arr[i] > *mx) *mx = arr[i];
    }
}
int main() {
    int a[6] = {45, 12, 78, 3, 90, 56};
    int small, big;
    minMax(a, 6, &small, &big);      // addresses bheje
    printf("Smallest = %d, Largest = %d\n", small, big);
    // Output: Smallest = 3, Largest = 90 ✔
    return 0;
}
/* Program: sum aur average dono ek hi function se */
void stats(int a[], int n, int *sum, float *avg) {
    int i;
    *sum = 0;
    for (i = 0; i < n; i++) *sum += a[i];
    *avg = (float) *sum / n;
}
/* main me: stats(a, n, &s, &avg);
   printf("Sum = %d, Average = %.2f", s, avg); */

/* Program: pointer se string ki length (strlen ka apna version) */
int myStrlen(char *s) {
    int count = 0;
    while (*s != '\0') {      // jab tak null na mile
        count++;
        s++;                  // agle character par
    }

}

⚡ Rapid-fire 2-mark Q&A — poore syllabus ka nichod (viva + short answers ke liye)

  1. C ko "mother of all languages" kyun? Kyunki C++/Java/JavaScript/PHP/jaisi languages ka syntax aur concepts C se aaye, aur OS/kernels (Linux/Windows) bhi C me likhe gaye.
  2. Compiler aur interpreter me farak? Compiler poora program ek saath machine code me badalta hai (fast, error pehle milte hain); interpreter line-by-line chalata hai (Python).
  3. Header file kya hai? Ready-made function declarations ki file — #include se judti hai (stdio.h, math.h, string.h).
  4. Token kya hai? Program ka sabse chhota meaningful tukda — keyword, identifier, operator, literal, special symbol.
  5. Variable aur constant me farak? Variable ki value badal sakti hai; constant (const/#define) nahi badal sakti.
  6. Lvalue aur Rvalue? Lvalue memory location hai (left side — a), Rvalue value hai (5) — 5 = a; galat hai kyunki 5 lvalue nahi.
  7. #define PI 3.14; me galti kya hai? Semicolon — isse PI ki jagah "3.14;" replace ho jaayega. #define me ; nahi lagta.
  8. Garbage value kya hai? Bina initialize local variable me pehle se padi random value (auto variable ka default).
  9. Explicit aur implicit conversion ka farak? Implicit compiler khud karta hai (promotion, safe); explicit programmer (type) likhkar (data loss ho sakta hai).
  10. Operator aur operand? Operator kaam karne wala symbol (+); operand jis par kaam hota hai (a, b).
  11. Unary vs binary operator? Unary ek operand par (!a, a++, -a), binary do par (a+b, a>b).
  12. Short-circuit evaluation? && me pehla false → doosra check nahi; || me pehla true → doosra check nahi.
  13. sizeof function hai ya operator? Operator — compile time par size nikalta hai, parentheses optional hain.
  14. Entry aur exit controlled loop? Entry: condition pehle (for, while). Exit: body pehle, condition baad me (do-while, kam se kam 1 baar).
  15. Dangling else kya hai? Bina braces ke if-else me else sabse nazdeek wale if se jud jata hai — confusion.
  16. switch me default zaroori hai? Optional hai, par best practice — invalid input handle karne ke liye.
  17. Infinite loop ke kaaran? Update statement na hona, condition kabhi false na hona, galat semicolon (while(i<5);).
  18. Array ka size program chalte waqt badal sakte hain? Nahi — static array ka size compile time par fix hota hai (runtime ke liye dynamic memory chahiye).
  19. Array aur pointer ka ek farak? sizeof(arr) = poore array ka size; sizeof(p) = pointer ka size. Aur array ka naam constant address hai (badla nahi ja sakta).
  20. Row-major aur column-major? C row-major (pehle row bhar); FORTRAN column-major.
  21. '\0' aur '0' me farak? '\0' = null character (ASCII 0, string terminator); '0' = digit zero (ASCII 48).
  22. scanf("%s") ki kami? Space par ruk jata hai — multi-word input ke liye fgets/gets chahiye.
  23. gets() kyun mana hai? Buffer size check nahi karta — overflow ka risk (security issue).
  24. strlen aur sizeof me farak (array of chars)? strlen '\0' se pehle ke characters ginta hai; sizeof poore array ke bytes.
  25. Function prototype kyun likhte hain? Compiler ko pehle bata dete hain (return type + parameters), warna call par warning/error aa sakti hai.
  26. Actual vs formal parameter? Actual = call me bheji value; formal = definition ke dabbe jo value receive karte hain.
  27. Function se 2 values kaise? Pointers (call by reference) — address bhejo, function values likh dega.
  28. Recursion me base case kyun? Rukne ke liye — warna infinite recursion aur stack overflow.
  29. Recursion kab iteration se better? Tree/graph/Hanoi/quick-sort jaise problems me jahan solution recursive structure ka ho.
  30. Pointer ka size type par depend karta hai? Nahi — har pointer ka size same (4/8 byte machine ke hisaab se).
