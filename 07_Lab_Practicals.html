W1. Creating an Advertisement 🫙

Aim: MS Word me ek attractive advertisement banane ke liye formatting features ka use karna (font, colour, picture, shapes, text box, border — sab ek saath).

Steps:

  1. MS Word kholo → Ctrl + N se new blank document banao; page setup (Layout → Orientation → Portrait) set karo.
  2. Title likho: "GRAND SALE – 50% OFF!" → Home tab me font bold, size 36, colour red, alignment center (Ctrl + E). Title ko WordArt (Insert → WordArt) se fancy bhi bana sakte ho.
  3. Ek catchy line likho: "Har purchase par dhamaka! 10 Oct – 15 Oct" — size 14, italic, centre me.
  4. Insert → Pictures se product ki image dalo (ya Insert → Shapes → shapes se design banao). Image ke saath Text Wrapping (Square/Tight) lagao taaki text image ke aas-paas bahe.
  5. Insert → Text Box me offer details likho ("Buy 2 Get 1 Free", "Free Home Delivery") → box par border + fill colour lagao (Shape Format → Shape Fill / Shape Outline).
  6. Home → Bullets (ya Numbering) se product list banao: "Shoes, Bags, Watches, Cosmetics" — line spacing 1.15–1.5 rakho.
  7. Design → Page Borders se page par border lagao, ya Shapes se box/frame banao. (Design → Page Color se halka background bhi de sakte ho.)
  8. Neeche contact line dalo: mobile number, address, timing — size 12, bold.
  9. Poora layout ek baar Print Preview (Ctrl + P) me dekho — kuch bahar nahi ja raha? Margins adjust karo.
  10. Save: File → Save As → file name "advertisement.docx" → Save. (Lab file ke liye ek print/screenshot lo.)

Word features jo lab me dikhane hain: font formatting, paragraph alignment, line spacing, bullets/numbering, images + text wrapping, shapes, text boxes, WordArt, borders/shading, colours, page setup. "Advertisement = visual + short lines + offer highlight" — bas inka mel banao.

W2. Curriculum Vitae (CV/Biodata) 📄

Aim: MS Word me apna CV (resume) banana — table, formatting, bullets aur photo ka use karke (professional 1-page document).

Steps:

  1. New document kholo (Ctrl + N). Page margins set karo: Layout → Margins → Normal (1 inch) — CV me clean space zaroori hai.
  2. Naam sabse upar — bold, size 20–22, centre. Neeche ek line me contact info: phone, email, city (size 10–11) — sab centre me.
  3. Headings banao: "Career Objective", "Education", "Skills", "Projects/Achievements", "Hobbies" — har heading bold + underline (ya Home → Styles me "Heading 1" ka colour badal lo), heading ke neeche ek horizontal line (Insert → Shapes → Line) de do.
  4. Career Objective 2 lines me likho: "BCA student with strong interest in programming and web development; seeking opportunities to apply C, MS Office and problem-solving skills." (CV me "hardworking" jaisi generic line se bacho — example ke saath likho.)
  5. Education ke liye table banao: Insert → Table (3 columns × 4 rows) → header row: Qualification | Board/University | Year/Percentage → data bharo (10th, 12th, BCA Pursuing). Table me header row bold + shading lagao (Table Design → Shading).
  6. Skills me bullets use karo: C Programming, MS Word, MS Excel, HTML basics, typing speed, communication — jaise-jaise seekh rahe ho, add karte jao.
  7. Photo: Insert → Pictures → apni passport size photo → Picture Format → Crop (square) → size adjust (~3 cm × 4 cm) → top-right ya left me align karo.
  8. Professional look ke liye: Design → Page Borders (thin line) ya page ke left me ek vertical line (Shapes → Line) — dhyaan rakho, zyada design CV ko "shabby" banata hai.
  9. Spell check: Review → Spelling & Grammar (F7) chalao — CV me typo bilkul allowed nahi.
  10. Save: "myCV.docx" (aur saath me PDF banao: File → Save As → PDF) — company ko PDF hi bhejni chahiye.
CV ka golden rule (viva me bhi poochh sakte hain): 1 page, clean layout, no typo, honest information, action words ("developed", "designed", "managed"). Photo optional hota hai India me common hai, par international CV me nahi. Save .docx rakho aur export .pdf karo — formatting kahin bigdegi nahi. 📄✅

W3. Scientific Notations (Superscript/Subscript) 🔬

Aim: Scientific notations (x², H₂O, exponents, symbols) aur equations MS Word me banana — superscript/subscript aur Equation editor ka use.

Steps:

  1. Type karo: x2 → "2" select karo → Home → Font group → Superscript (x²) — shortcut: Ctrl + Shift + +.
  2. Type karo: H2O → "2" select karo → Subscript (H₂O) — shortcut: Ctrl + =.
  3. Symbols ke liye: Insert → Symbol → More Symbols → π, α, β, °, →, ≥, √, Ω, µm select karke insert karo.
  4. Equation ke liye: Insert → Equation (Alt + =) → type karo "E=mc^2" → space dabao = E = mc². Fraction ke liye (a+b)/(c+d) likhke space dabao → proper fraction ban jaayega.
  5. Practice karo (ye 6 cheezein lab file me likho): "Area = πr²", "E = mc²", "C₆H₁₂O₆", "10⁻³", "H₂SO₄", "v² = u² + 2as"
  6. Save "scientific_notation.docx" → screenshot lab file me lagao.

Kyun zaroori hai: Chemistry ke formulas (H₂O, CO₂), Maths ke exponents (x² + y², aⁿ), Physics ke units (m/s², cm³), aur engineering me chemical equations — sab jagah superscript/subscript use hota hai. University practical me ye dikhana 5 minute ka kaam hai aur easy marks ✅. Viva me poochha jaata hai: "superscript aur subscript me difference?" → Superscript upar likha jaata hai (power/exponent, x²), subscript neeche (index/chemical count, H₂O).

W4. Creating a Timetable 📅

Aim: MS Word me ek class timetable banana — table banana, cells merge karna, shading aur row height set karna.

Steps:

  1. Insert → Table → 6 columns × 7 rows (pehli row = header "Day/Period", baaki rows = Monday–Saturday).
  2. Header row bharo: Time | Day | 9:00–10:00 | 10:00–11:00 | 11:00–12:00 | 12:00–1:00 — aur ek "Lunch Break" column bhi add karo (ek column zyada le lo).
  3. Subjects type karo — har cell me subject ka naam + teacher ka naam (chhota font, size 10–11).
  4. Merge Cells: "Lunch Break" ke rows select karo → right-click → Merge Cells → ek hi cell ban jaayega (ya Table Layout → Merge Cells). Lunch break ki shading alag colour do.
  5. Table Design → Shading se header row ko colour do (halka neela/green) aur Bold karo; border style bhi badal sakte ho (Table Design → Borders).
  6. Row height / column width adjust karo: table pe right-click → Table Properties → Row/Column (ya borders ko drag karo) — sab cells barabar dikhein.
  7. Table ke upar title likho: "BCA 1st Semester — Class Timetable (Session 2025-26)" — bold, centre, size 16; neeche "Class Teacher" ke sign ka space chhodo.
  8. Save "timetable.docx" → print preview me check karo ki ek page me aa raha hai (Layout → Orientation → Landscape bhi try kar sakte ho).

Tip: "Insert → Table" ke bajaye Table Draw karke bhi bana sakte ho; column width adjust ke liye border pe drag karo. Viva me aata hai: "cell merge kaise karte hain?" → Table Layout/Design → Merge Cells (ya select + right click). Ye practical table + merge + shading + properties — 4 features ka proof hai ✅

W5. Conversion (Document Conversion / Units Table) 🔁

Aim: Conversion se do cheezein — (a) units ka conversion table Word me banana, (b) document ko ek format se doosre format me convert karna (Word ↔ PDF).

Steps (a) — Units Conversion Table:

  1. Insert → Table (3 columns × 6 rows) → headers: "Quantity | Unit | Conversion".
  2. Rows bharo: Length — 1 km = 1000 m, 1 m = 100 cm, 1 cm = 10 mm; Weight — 1 kg = 1000 g, 1 quintal = 100 kg, 1 tonne = 1000 kg; Temperature — °C → °F = (C × 9/5) + 32.
  3. Formula wali cells me Insert → Equation use karo (proper notation ke liye) aur "°C / °F" symbols Insert → Symbol se dalo.
  4. Table ko bold header + shading + alignment de do; title: "Common Unit Conversions" — aur save "conversion_table.docx".

Steps (b) — File Conversion:

  1. Word → PDF: File → Save As (ya Export) → File type "PDF (*.pdf)" → Save. (PDF ka fayda: formatting kahin nahi badalti, har device pe same dikhta hai.)
  2. PDF → Word: Word kholo → File → Open → PDF file select karo → Word usko convert karke dikhata hai → "OK" → phir Save As → .docx.
  3. Screenshot/doc ko image me badalna: Select karo → Ctrl + C → Paint/MS Paint me paste → Save as .png (lab file me lagane ke liye).
Real use: Assignment/notes Word me banao, PDF me submit karo (teacher ka format same rehta hai); online forms me PDF hi maanga jaata hai. Aur Word ↔ PDF conversion viva ka favourite question hai — "PDF ka poora naam kya hai?" → Portable Document Format (Adobe, 1993). 📄➡️📕

W6. Mail Merge and Letter ✉️ Important

Aim: Mail Merge ka use karke ek hi letter ka template bana kar kai logon ke liye personalized letters generate karna (naam, city, amount apne-aap bhar jaayein).

Mail Merge kya hai? Ek main document (template) + ek data source (list of recipients) ko jod kar, Word har recipient ke liye alag letter bana deta hai — "ek template + ek data list = 100 letters, 2 minute me!" 😎

Steps:

  1. Main document banao: Letter ka format likho — letterhead (university/company ka naam + address + date), salutation, body, closing. Jahan naam/address aayega wahan placeholder soch lo: "Dear «Name», aapko suchit kiya jaata hai…"
  2. Recipient list banao: Mailings tab → Start Mail Merge → Letters → Select Recipients → Type a New List → Customize Columns: Name, City, Amount (jo fields chahiye) → 5–10 logon ka data bharo → save kar do (Word usko .mdb / merge list ke roop me rakhta hai).
  3. Placeholders lagao: Mailings → Insert Merge Field → «Name», «City», «Amount» letter me sahi jagah daalo (fields « » brackets me dikhte hain).
  4. Preview Results (Mailings tab) → Next record arrow se ek-ek letter check karo — «Name» ki jagah Rahul, Priya sab aa rahe hain?
  5. Finish & Merge → "Print Documents" (seedha print) ya Edit Individual Documents (saare letters ek hi file me alag pages par — isko lab file me output ke roop me lagao).
  6. Letters ki copy save karo ("merged_letters.docx") aur data list bhi ("recipients.docx") — record me dono ka zikr karo.
Sample merged letter (har name ke liye auto-bana):

Aapka admission form «City» campus me receive ho gaya hai.

Admission Cell

Rahul | Kichha | 5000

Viva me poochha jaata hai: (1) Mail merge ke 3 parts? → Main document, Data source, Merged document (2) Kab use karte ho? → Bulk letters, fee notices, admit cards, invitation letters, salary slips, certificates (3) «» ka kya matlab? → Merge field ka placeholder. W7. Drawing a Flowchart 🗺️

Aim: MS Word ke Shapes aur Connectors se ek flowchart banana (algorithm ko picture me dikhana).

Steps:

  1. Insert → Shapes → Oval (Start/Stop), Parallelogram (Input/Output), Rectangle (Process), Diamond (Decision), arrows/lines (Connectors) chuno.
  2. Pehla shape girao (Oval → "Start") → shape ke andar text likho: shape pe right-click → Add Text (ya seedha type karo).
  3. Aage ke shapes girao: "Read a, b" (Parallelogram) → "if a > b?" (Diamond) → "print a" (Parallelogram) → "print b" → "Stop" (Oval).
  4. Shapes ko Connectors (Lines/Elbow arrows) se jodo — arrows shape ke edge pe snap hote hain (shape hilao to arrow bhi saath chalega — isi ko "smart" connection kehte hain).
  5. Decision diamond se do arrows nikalo: Yes aur No — arrows ke paas label likho (Insert → Text Box se chhota text).
  6. Colours/borders se Start-Stop ko green, Process ko blue, Decision ko yellow kar do; font size 11 baaki sab me same rakho.
  7. Poora flowchart select karo (Ctrl + A ya drag) → Right click → Group → Group (ya Ctrl + G) — ab poori figure ek unit ki tarah move hogi.
  8. Save "flowchart.docx" → screenshot lab file me (aur haath se bana flowchart bhi record me draw karo — dono alag marks hain).
Flowchart symbols — yaad rakho (viva favourite!):

  ( Oval )          → Start / Stop (terminal)
  [ Rectangle ]     → Process (kaam/hisaab)
  / Parallelogram / → Input / Output (read/print)
  <> Diamond <>     → Decision (condition: yes/no)
  → Arrow           → Flow direction (connector)

Example banao: "Largest of two numbers" ka flowchart:
Start → Read a, b → a > b ? → Yes: print a ; No: print b → Stop

(Aur practice karo: even/odd, sum of 1..n, average of 3 numbers — 
ye Unit 1 me padha tha, ab Word me shapes se draw karo ✅)

Viva me aata hai: "Flowchart ke 4 main symbols batao" (upar wale), "Algorithm aur flowchart me difference?" → Algorithm = steps in words, flowchart = same steps ki picture/diagram (symbols me). Ye practical C lab ke "algorithm likhna" wale question se seedha juda hua hai — dono ek hi cheez ke do roop hain 🔁

1. Temperature: Celsius → Fahrenheit 🌡️

Aim: Input me di gayi Celsius temperature ko Fahrenheit me convert karna.

(Aur idea: 0°C = 32°F, 100°C = 212°F — formula ke andar yahi khayal hai)

2. Simple Interest & Compound Interest 💰

Aim: Principal, Rate aur Time input lekar Simple Interest (SI) aur Compound Interest (CI) nikalna.

Algorithm: Start → p, r, t read karo → si = (p × r × t) / 100 → ci = p(1 + r/100)t − p → dono print karo → Stop.

#include <stdio.h>
#include <math.h>
int main() {
    float p, r, t, si, ci;
    printf("Enter Principal, Rate, Time: ");
    scanf("%f %f %f", &p, &r, &t);

    si = (p * r * t) / 100;                 // SI = P×R×T/100
    ci = p * pow((1 + r / 100), t) - p;     // CI = P(1+R/100)^T − P

    printf("Simple Interest = %.2f\n", si);
    printf("Compound Interest = %.2f\n", ci);
    return 0;
}
Input: 10000 5 2
Simple Interest = 1000.00
Compound Interest = 1025.00
(Kyun CI zyada? Kyunki CI me "interest pe bhi interest" milta hai 😄)

Line-by-line samjho: #include <math.h> iss program me isliye lagta hai kyunki pow() function use kiya (power nikalta hai) • pow((1 + r/100), t) = (1 + R/100)t — pow ka first argument base, second exponent • CI me sirf interest nikaalne ke liye akhir me − p kiya (total amount − principal) • CI hamesha SI se zyada ya barabar hota hai (compound me interest par bhi interest lagta hai) • Ek hi scanf me teen values: "%f %f %f" — user space ya enter se teeno de sakta hai.

Viva point: "SI aur CI me basic difference?" → SI sirf principal par lagta hai (har saal same), CI principal + jama hua interest dono par lagta hai (isliye badhta jaata hai). Formula bhi yaad rakho: SI = PRT/100 • CI = P(1+R/100)ᵗ − P.

Real life: Bank FD par SI, loan/bachat schemes me CI — "5% interest 2 saal" ka matlab depend karta hai compounding par. Isi liye SIP aur compound interest me paisa tez badhta hai — Einstein se juda famous quote: "compound interest duniya ka 8th wonder hai." 💹

4. Swap Two Numbers — with third variable 🔄

Aim: Do numbers ki values ko ek temporary (third) variable ki madad se exchange karna.

Algorithm: Start → a, b read karo → temp = a → a = b → b = temp → naye a, b print karo → Stop.

#include <stdio.h>
int main() {
    int a, b, temp;
    scanf("%d %d", &a, &b);
    printf("Before: a=%d b=%d\n", a, b);

    temp = a;     // a ko temp me rakha
    a = b;        // b ki value a me
    b = temp;     // temp (purana a) b me

    printf("After : a=%d b=%d", a, b);
    return 0;
}
Input: 10 20  →  After: a=20 b=10
(Glass analogy: do glass ka paani exchange karna — ek khaali glass (temp) chahiye!)

Viva point: "Temp variable ke bina swap ho sakta hai?" → Haan (a = a + b; b = a − b; a = a − b wala tarika — agla program) — par safe/recommended third variable wala hi hai (bade numbers me addition overflow kar sakta hai).

8. Roots of Quadratic Equation (ax² + bx + c = 0) 🧮

Aim: a, b, c input lekar quadratic equation ke roots nikalna — discriminant (d) ke aadhaar par teen cases (real & distinct, real & equal, complex).

Algorithm: Start → a, b, c read karo → d = b² − 4ac → agar d > 0: r1, r2 = (−b ± √d)/2a • agar d = 0: r = −b/2a • warna complex roots print karo → Stop.

#include <stdio.h>
#include <math.h>
int main() {
    float a, b, c, d, r1, r2;
    printf("Enter a, b, c: ");
    scanf("%f %f %f", &a, &b, &c);

    d = b * b - 4 * a * c;                  // discriminant

    if (d > 0) {
        r1 = (-b + sqrt(d)) / (2 * a);
        r2 = (-b - sqrt(d)) / (2 * a);
        printf("Real & distinct roots: %.2f and %.2f", r1, r2);
    } else if (d == 0) {
        r1 = -b / (2 * a);
        printf("Real & equal roots: %.2f", r1);
    } else {
        printf("Complex roots: %.2f + %.2fi and %.2f - %.2fi",
               -b/(2*a), sqrt(-d)/(2*a), -b/(2*a), sqrt(-d)/(2*a));
    }
    return 0;
}
Input: 1 -5 6  →  Real & distinct roots: 3.00 and 2.00
(d > 0: do roots, d = 0: ek root, d < 0: complex roots — Sridharacharya formula)

Line-by-line samjho: d (discriminant) hi poore program ka "judge" hai — usse pata chalta hai roots ki nature • sqrt(d) ke liye math.h zaroori • d < 0 par sqrt(negative) nahi hota (error!) isliye sqrt(-d) liya aur "i" (imaginary unit) print kiya • if-else if-else ladder — ek hi case chalega • Har case me %.2f rakha taaki output clean dikhe.

Viva point: "Discriminant kya batata hai?" → d > 0 = real & distinct (do alag roots) • d = 0 = real & equal • d < 0 = complex/imaginary roots (graph x-axis ko touch nahi karta). Formula: x = (−b ± √(b² − 4ac)) / 2a.

9. Armstrong Number 💪

Aim: Check karna ki input number Armstrong hai ya nahi (3-digit ke liye: har digit ka cube jodkar wahi number aana chahiye).

Algorithm: Start → n read karo → temp = n, sum = 0 → jab tak temp ≠ 0: digit = temp % 10; sum = sum + digit³; temp = temp / 10 → agar sum = n to Armstrong warna nahi → Stop.

#include <stdio.h>
int main() {
    int n, temp, r, sum = 0;
    scanf("%d", &n);
    temp = n;
    while (temp != 0) {
        r = temp % 10;        // digit nikala
        sum += r * r * r;     // cube joda
        temp /= 10;
    }
    if (sum == n)
        printf("%d is Armstrong", n);
    else
        printf("%d is not Armstrong", n);
    return 0;
}
153 = 1³+5³+3³ = 1+125+27 = 153 ✔ Armstrong
370, 371, 407 bhi Armstrong hain (3-digit). 1634 bhi hota hai (4-digit, 4th power se!)

Line-by-line samjho: temp = n isliye kiya kyunki loop me n toot jaata hai (n ki original value compare ke liye chahiye) • temp % 10 = aakhri digit • temp / 10 = aakhri digit hata do (integer division!) • sum += r*r*r me cube joda • Ant me sum == n check — original value se compare • Yehi "digit extraction" trick aage har number program (palindrome, sum of digits, reverse) me kaam aati hai.

Viva point: "Armstrong number ki definition?" → Jis number ke digits ke number-of-digits wale power ka sum us number ke barabar ho (3 digits → cube, 4 digits → 4th power). "4-digit wale program me kya badlega?" → r*r*r*r (ya r ki power n) — isliye general program me power = digits count karke lagate hain.

P1. Largest of Two / Three Numbers — if aur conditional operator se ⚖️

Aim: Do aur teen numbers me sabse bada number dhoondhna — pehle nested if-else se, phir conditional (ternary) operator se.

Algorithm: Start → a, b, c read karo → agar a ≥ b aur a ≥ c to a largest • warna agar b ≥ a aur b ≥ c to b largest • warna c largest → print → Stop.

/* Largest of THREE numbers — nested if-else se */
#include <stdio.h>
int main() {
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);

    if (a >= b && a >= c)
        printf("%d is largest", a);
    else if (b >= a && b >= c)
        printf("%d is largest", b);
    else
        printf("%d is largest", c);
    return 0;
}
Input: 12 45 30 → 45 is largest

/* Same with conditional (ternary) operator — ONE LINE me! */

Concept samjho: if-else ladder me pehli condition sach hui to baaki check hi nahi hoti (short-circuit) • && (AND) ka matlab dono conditions sach honi chahiye — isliye "a ≥ b AND a ≥ c" likha • Ternary ka form: (condition) ? true-value : false-value — isme nested ternary se ek hi line me teeno numbers compare ho gaye • Largest nikaalne ka sabse simple tarika: pehle do me bada nikaal lo, phir usse teesre se compare karo big = (a > b ? a : b); big = (big > c ? big : c);

Viva point + common mistake: (a) "if-else aur ternary me kya chuno?" → simple do-choice ke liye ternary, multi-branch logic ke liye if-else (readability better) (b) common mistake: a > b likh dena jab a == b bhi handle karna ho (equal values par "c is largest" print ho jaata hai) — isliye >= use karo. ✅

P2. Reverse of a Given Number 🔄

Aim: Input number ke digits ko ulta karke print karna (aur bonus me palindrome check karna).

#include <stdio.h>
int main() {
    int n, rev = 0, r;

P4. Roots of Quadratic Equation using SWITCH 🔀

#include <stdio.h>

    if (d > 0) d = 1;
    else if (d == 0) d = 0;
    else d = -1;

            break;
        case -1:
            printf("Complex roots: %.2f ± %.2fi",
                   -b/(2*a), sqrt(-(b*b - 4*a*c))/(2*a));
            break;
    }
    return 0;
}

P7. Product of Two Matrices ✖️

Aim: Do matrices ka multiplication karna — dimension check (c1 = r2), 2D arrays aur 3 nested loops ke saath.

#include <stdio.h>
int main() {
    int a[10][10], b[10][10], prod[10][10];
    int r1, c1, r2, c2, i, j, k;

    printf("Rows & cols of A: ");
    scanf("%d %d", &r1, &c1);
    printf("Rows & cols of B: ");
    scanf("%d %d", &r2, &c2);

        printf("Multiplication not possible (c1 != r2)");
        return 0;
    }

    printf("Enter matrix A:\n");
    for (i = 0; i < r1; i++)
        for (j = 0; j < c1; j++)
            scanf("%d", &a[i][j]);

    printf("Enter matrix B:\n");
    for (i = 0; i < r2; i++)
        for (j = 0; j < c2; j++)
            scanf("%d", &b[i][j]);

    for (i = 0; i < r1; i++) {
        for (j = 0; j < c2; j++) {
            prod[i][j] = 0;

                prod[i][j] += a[i][k] * b[k][j];
            }
        }
    }

    printf("Product:\n");
    for (i = 0; i < r1; i++) {
        for (j = 0; j < c2; j++)
            printf("%d ", prod[i][j]);
        printf("\n");
    }
    return 0;
}

P8. GCD of Two Numbers — Iteration aur Recursion dono 🌀

Aim: Do numbers ka GCD (Greatest Common Divisor / HCF) nikalna — pehle loop (Euclid's algorithm) se, phir recursion se.

Algorithm: Start → a, b read → jab tak b ≠ 0: t = b; b = a % b; a = t → a print (iterative). Recursive: gcd(a,b) = gcd(b, a % b), base case b = 0 → a.

/* (a) Iteration se (Euclid's algorithm) */
#include <stdio.h>
int main() {
    int a, b, t;
    scanf("%d %d", &a, &b);
    while (b != 0) {
        t = b;
        b = a % b;      // remainder
        a = t;
    }
    printf("GCD = %d", a);
    return 0;
}
Input: 36 60 → GCD = 12

/* (b) Recursion se */
int gcd(int a, int b) {
    if (b == 0)
        return a;                  // base case
    return gcd(b, a % b);          // khud ko chhote input se call
}

P10. Call by Value vs Call by Reference 🔄

Aim: Function me argument bhejne ke do tarike — call by value (copy) aur call by reference (address) ka difference practically dikhana (swap ke example se).

Algorithm: Start → do functions banao: swapValue(x, y) int leta hai, swapRef(*x, *y) pointer leta hai → main me a = 10, b = 20 le kar dono functions call karo → har call ke baad main ki values print karke difference dekho → Stop.

#include <stdio.h>

void swapValue(int x, int y) {         // copies aayi
    int t = x;  x = y;  y = t;
    printf("Andar (value):     x=%d y=%d\n", x, y);
}

void swapRef(int *x, int *y) {         // addresses aaye
    int t = *x;  *x = *y;  *y = t;
    printf("Andar (reference): x=%d y=%d\n", *x, *y);
}

int main() {
    int a = 10, b = 20;

    swapValue(a, b);
    printf("main me (baad value):     a=%d b=%d\n", a, b);   // 10 20 — no change!

    swapRef(&a, &b);
    printf("main me (baad reference): a=%d b=%d\n", a, b);   // 20 10 — changed ✔
    return 0;
}

Andar (reference): x=20 y=10

    printf("strcmp(BCA,BCA)  = %d\n", strcmp("BCA", "BCA"));    // 0 = equal
    printf("strcmp(BCA,ABC)  = %d\n", strcmp("BCA", "ABC"));    // +ve: BCA bada

    printf("strrev-like reverse: ");
    for (int i = strlen(c) - 1; i >= 0; i--)   // manual reverse
        printf("%c", c[i]);
    printf("\n");

    printf("strupr/lwr: %s | %s\n", strupr(c), strlwr(c));  // Turbo C
    return 0;
}

P14. Count Characters in a File 📁

Aim: Kisi file ko read karke usme total kitne characters hain — count karna (file handling ka poora cycle).

Algorithm: Start → filename input lo → fopen(file, "r") → agar NULL to error message → jab tak fgetc(fp) ≠ EOF: count++ → fclose → count print → Stop.

#include <stdio.h>
#include <stdlib.h>

int main() {
    FILE *fp;
    char filename[50], ch;
    long count = 0;

    printf("Enter file name: ");
    scanf("%s", filename);

    fp = fopen(filename, "r");       // r = read mode
    if (fp == NULL) {
        printf("File open nahi hui! (naam/galat path check karo)");
        return 1;
    }

    while ((ch = fgetc(fp)) != EOF)   // ek-ek character padho
        count++;                      // EOF = End Of File

    fclose(fp);                       // file band karna zaroori!
    printf("Total characters = %ld", count);
    return 0;
}

Total characters = 1240

File handling ke 4 steps yaad rakho: 
fopen → check (NULL?) → fgetc/fputc/fprintf in loop → fclose ✔

Concept samjho: File handling ke 4 steps hamesha yaad rakho: fopen (open) → NULL check (file mili ya nahi) → read/write loop → fclose (band karna zaroori!) • FILE *fp ek "handle" hai — file se baat karne ka pointer • fgetc(fp) file se ek-ek character padhta hai aur aage badhta jaata hai (cursor ki tarah) • EOF = End Of File — file khatam hone par loop ruk jaata hai • NULL check ka matlab: file ka naam galat hua to program crash nahi hoga, saaf message dega ✅

Isme kya sikha: file handling ka poora cycle — fopen/fgetc/fclose, NULL check, EOF concept. Ye C lab ka sabse important "real programming" program hai, aur Project/record me bhi yahi base aata hai.

Viva point: "File ke modes?" → r (read), w (write — purana data delete!), a (append — ant me jodta hai), r+ (read + write), w+, a+, aur binary ke liye rb/wb • "fclose na karein to?" → data buffer se disk par nahi likha jaata (data loss), aur file doosre programs ke liye locked reh sakti hai ⚠️

P15. Structure Student — 10 Students File me 📝

Aim: structure Student (roll_no, name, class, year, total_marks) banakar 10 students ka data input le kar file me save karna (array of structures + fprintf).

Algorithm: Start → struct Student define karo → struct Student s[10] → fopen("students.txt", "w") + NULL check → loop 10 baar: scanf se data lo, fprintf se file me likho → fclose → "save ho gaya" print → Stop.

#include <stdio.h>

struct Student {                     // apna "data type" banaya
    int roll_no;
    char name[30];
    char class[10];
    int year;
    float total_marks;
};

int main() {
    struct Student s[10];            // 10 students ka array
    FILE *fp;
    int i;

    fp = fopen("students.txt", "w");  // w = write mode
    if (fp == NULL) {
        printf("File nahi khuli!");
        return 1;
    }

    for (i = 0; i < 10; i++) {
        printf("Student %d — Roll, Name, Class, Year, Marks: ", i + 1);
        scanf("%d %s %s %d %f", &s[i].roll_no, s[i].name,
              s[i].class, &s[i].year, &s[i].total_marks);

        fprintf(fp, "%d %s %s %d %.2f\n", s[i].roll_no, s[i].name,
                s[i].class, s[i].year, s[i].total_marks);   // file me likho
    }

    fclose(fp);
    printf("10 students ka data students.txt me save ho gaya ✔");

    // (Bonus: same file wapas padho — fehif ("students.txt","r") + fscanf)
    return 0;
}

P16. Copy File — Lowercase → UPPERCASE 🔠

Aim: Ek file ko doosri file me copy karna, saath hi saare small (lowercase) letters ko CAPITAL (uppercase) me badal dena — character-by-character processing.

Algorithm: Start → src = fopen("input.txt", "r") + NULL check → dest = fopen("output.txt", "w") → jab tak fgetc(src) ≠ EOF: agar 'a'–'z' hai to toupper() → fputc(ch, dest) → dono files fclose → message print → Stop.

#include <stdio.h>
#include <ctype.h>

int main() {
    FILE *src, *dest;
    char ch;

    src = fopen("input.txt", "r");
    if (src == NULL) {
        printf("Source file nahi mili!");
        return 1;
    }
    dest = fopen("output.txt", "w");

    while ((ch = fgetc(src)) != EOF) {
        if (ch >= 'a' && ch <= 'z')
            ch = toupper(ch);        // small → CAPITAL
        fputc(ch, dest);             // destination me likho
    }

    fclose(src);
    fclose(dest);
    printf("File copy ho gayi (lowercase → UPPERCASE) ✔");
    return 0;
}
input.txt :  "bca first semester" 
output.txt:  "BCA FIRST SEMESTER"

Note: ctype.h ke toupper/tolower hi asli kaam kar rahe hain — 
condition: sirf lowercase letters badlenge, baaki characters (space, ., numbers) same rahenge!

Concept samjho: Ek saath do files — ek read mode me (src), ek write mode me (dest) • Loop me ek character src se uthao → transform karo → dest me likho (bilkul assembly line ki tarah) • toupper() (ctype.h) sirf lowercase letters ko badalta hai; baaki characters (space, '.', digits) waise hi rahenge — isliye condition lagayi (ch ≥ 'a' && ch ≤ 'z') • EOF par loop rukta hai aur dono files band ho jaati hain • Isi logic se "file copy" ka general program banta hai — bas conversion hata do (toupper ki line delete) 😄

Isme kya sikha: do files ek saath handle karna (read + write), character-by-character processing, toupper/tolower ka use — "file copy with transformation" ek real utility program hai.

Viva point: "File copy ka command?" → Linux/mac me cp, Windows me copy — par humne yahan apna program likha (logic clear karne ke liye) • "Binary file copy me kya badlega?" → rb/wb modes + fread/fwrite (fgetc/fputc nahi, warna special bytes/garbage handle karna mushkil) • "tolower/toupper kahan define hain?" → ctype.h 🔠 | "Sirf letters badalne ke liye condition kyun?" → taki punctuation aur digits na badlein.
